## 完成记录（10-15，主控）

### 做了什么
- `window_inbox.rs` 画界面的三个函数（弹层、名单、右边）照样稿甲重画；逻辑（`inbox.rs`、选中、读过、发送、键盘）没动。`Reading` 多带一个 agent 种类，只为画头像。

- 名单栏：底色叠一半侧栏色；顶上 `Inbox` 15pt、强调色个数、⇧⌘A 键帽；分组名按组上色；行圆角 10、选中淡强调色、悬停淡亮、没读的新回复带强调色小圆点；底部一行 `⌃Tab next`、`Esc close`（原来右边那行快捷键去掉了）。
- 右边：32pt 淡色方块里的 agent 图标（没有图标的画状态点）、名字、“状态 · 多久前”；`Open pane` 淡底加外跳箭头；原文、提示条、`You · sent` 和名字左对齐，提示条和已发那块去掉描边。
- 回复框：一整块圆角 14 的输入区，聚焦时强调色边；右下 `⇧↩ new line` 和 30pt 圆形发送键（有字时强调色、没字灰、发送中变淡）；不能回时这块里写原因；被拒的原因照旧在下面。输入区最低从 54 降到 44。
