## 要做的
1. **回看历史时按像素滚**（只管上面第三条分支，以及暂停的 agent）：

## 完成记录

### 做了什么
- 新模块 `app/src/view/glide.rs`：平滑滚动的规则，只算数，不碰 GPUI。alacritty 照旧管整行偏移（`display_offset`），`Glide` 只记整行之外不到一行的像素和滚轮的滑动。
  - `drag`：触控板给的像素（包括 macOS 送来的惯性事件，GPUI 把它们当普通滚动事件、`Pixels` 送来）立即移动，跨行时换算成整行交给 alacritty，余下的留作像素；滑到一半的滚轮滑动随之停掉。
  - `wheel`／`frame`：滚轮给的行（`Lines`）换成像素，150ms 内 ease-out 三次方滑到；连着滚，从没走完的剩余接着滑，计时重新开始；反方向滚，丢掉旧方向没走完的部分（和原来 `Scroll::lines` 换方向丢余数一样）。
  - 到顶（历史最早一行）、到底停住，停住时像素归零，不留半行；滑动碰到两头立即结束。历史变短（清屏、切到全屏程序的另一屏）后像素也归零。
  - `wheel_goes`：从原来的 `scroll_wheel` 抽出的分流规则（报给程序／发方向键／滚历史），只有第三条走像素。
  - `shift`：画的偏移取整到设备像素，相邻两行底色的边落在同一条像素线上。
- `view.rs`：
  - `scroll_wheel`：滚历史且开关开着时走 `glide_by`；报给程序、发方向键两条照旧按行攒（`Scroll::lines` 不变）。系统“减少动态效果”时滚轮不滑、直接到位。推过两头、画面没动时不重画。
  - `build`：每帧先推进滑动、把整行交给 alacritty；还在滑就 `request_animation_frame`，滑完不再要帧，不留定时器。偏移大于 0 时多读一行（第 -1 行）。
  - `Frame`：所有格子内容（底色、画框字符、文字、光标、OSC 8 提示）按偏移往下画（`at` 里加），第 -1 行画在最上面；偏移大于 0 时裁到格子区域（宽同窗格，高 = 行数 × 行高），不画到窗格外面。光标的位置交给 `caret` 时不含偏移，所以滚动不会让光标滑动。出错说明那行字照旧不跟偏移走。
  - 跟着偏移走：`cell_at`（点、拖选、双击三击、⌘ 悬停和点击链接、报给程序都用它）按偏移换算，画面最上面那半行算第 -1 行；报给程序的行号最小为 0。`tag_top`（名字签）、输入法候选框的位置加上偏移。
  - 回到整行：打字（`write`）、关查找、查找或命令面板跳到结果、关掉开关、改字体／行高时，像素和滑动清掉。
- `rows::read` 的行号改成 `i32`，可读第 -1 行。`grid::cell_at` 加偏移参数，返回的行号改成 `i32`。
- 设置：`config.rs` 加 `smooth_scroll`（默认 true）；Settings › General › Terminal 加 `Smooth scrolling`（在两个光标开关后面），改了立即生效（`window.rs` 的 `apply` → `TerminalView::set_smooth_scroll`）；关掉回到按行滚。

### 拿主意的地方
- 滚轮一格滑 150ms，ease-out 三次方（先快后慢）。一格滑多远沿用原来的行数（GPUI 给多少行就滑多少行 × 行高），只是从跳变成滑。
- 惯性：不自己做物理。macOS 惯性阶段的事件 GPUI 也是作为 `Pixels` 滚动事件送来（`phase` 为空时是 `Moved`），照样立即移动；`touch_phase` 没用上。
- 跳回底部、跳到查找结果：不带滑动，直接到位（打字时画面应该立刻在底部；跳到结果也一下到位，和原来一样）。
- 停在半行：手指停在哪就停在哪，不自动吸附到整行；只在到底、到顶时保证整齐。
- 光标：只在整行偏移为 0 时画（P5-143c1 的规则不变），所以往回翻不到一行时光标跟着内容往下移，翻过一行就不画了。
- 裁剪：只在偏移大于 0 时裁，裁到格子区域（行数 × 行高）而不是整个窗格，免得最后一行在窗格底部余下的空隙里露一截、跨行时一闪；偏移为 0 时不裁，和原来完全一样。
- 偏移取整到设备像素（Retina 上是半个点），鼠标换算也用同一个取整后的值，画的和点的一致。
