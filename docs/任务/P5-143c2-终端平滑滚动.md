## 现在是怎样（主控 10-19 对着代码核对的）
- 滚动在 `app/src/view.rs` 的 `scroll_wheel`（约 1375 行）：触控板给的像素和鼠标滚轮给的行都换算成行，`grid::Scroll::lines`（`app/src/grid.rs`）攒到满一整行才滚，用 alacritty 的 `scroll_display(Delta(行数))`。所以触控板慢慢推时一顿一顿，滚轮一格一下跳三行。
- 三条分支：程序要了鼠标（`MOUSE_MODE`，不按 ⇧）报给程序；全屏程序（`ALT_SCREEN | ALTERNATE_SCROLL`）发方向键；其余才是滚历史。暂停的 agent 也滚历史。
- 画格子按整行：`build` 读 `display_offset`，每行画在 `row × 行高`。依赖这个偏移的地方：`cell_at`／`locate`（鼠标在哪一格，拖选、点链接、报给程序都用它）、`build` 里找 ⌘ 悬停的链接和 `tip`（OSC 8 地址提示的位置）、`tag_top`（名字签找空行）、`find.rs`（查找把结果滚进视野）、`rows.rs`（读一行）。光标只在 `display_offset == 0` 时画（P5-143c1 的 `caret` 也按这个）。
- 打字（`write`）、选中查找结果会把视野拉回底部或跳到结果，都是整行。
- GPUI 的 `ScrollWheelEvent` 带 `touch_phase`（`Started`／`Moved`／`Ended`／`Cancelled`）；macOS 的触控板惯性也是以滚动事件送来的。

## 要做的
1. **回看历史时按像素滚**（只管上面第三条分支，以及暂停的 agent）：
   - 触控板：手指推多少画面走多少，跟手，不再攒满一行才动；松手后的惯性照 macOS 送来的事件走，不自己另做物理。
   - 鼠标滚轮（按行给的）：每一格滑过去（一百多毫秒内缓动到位），连着滚就接着滑，不一下跳三行。
   - 到顶（历史最早一行）、到底（最新的一行）停住，不越界、不回弹也可以；停在底部时不留半行偏移，画面和现在一样整齐。
2. **画法**：在整行偏移之外加一个不到一行的像素偏移；上面多画一行、超出窗格的部分裁掉，窗格边上不露空、不画到窗格外面。
3. **跟着偏移走**：鼠标点在哪一格、拖选（包括拖到窗格外自动滚）、双击三击、⌘ 悬停链接的下划线和 `tip`、名字签找空行、查找跳到的结果，在半行偏移时都要对准画面上看到的那一格。
4. **不变的**：程序要了鼠标、全屏程序里的滚动和现在完全一样（报给程序、发方向键，按行攒）；打字、粘贴、选中查找结果时回到底部或跳到结果，照旧（是否带一点滑动，开发自己定，写进完成记录）；没在滚的窗格不重画（P5-143a、P5-143c1 的省 CPU 不能丢：滑完就停，不留一直醒的定时器）。
5. **开关**：Settings › General › Terminal 加 `Smooth scrolling`，默认开；关掉就回到现在按行滚的样子。（和 P5-143c1 的两个光标开关一样，留个退路；用户 10-19 同意。）
