# 任务 P2-2：标签页与分屏

2026-10-05，paddock/main 自己做。
类型：功能变更
依据：DESIGN §11 第 2 项。照 Saddle 的标签页和分屏规则（Saddle `df1c727` 的 `docs/DESIGN.md` §27、§30、§39 及用户截图），外观用 GPUI 做得比 TUI 好看，信息和功能不少于 Saddle；切走时 shell 不再结束。

## Saddle 的规则（照做）

- 一个标签页保存一组窗格和其中的活动窗格；只在本次运行期间保留（布局保存是第三阶段）。
- 分屏相对于活动窗格，上下左右四个方向。
- 点标签切换布局，点窗格切换键盘输入目标。
- 从侧栏接入 agent：放进活动窗格；**同一 agent 已在任何标签页或窗格打开时，转到那里，不重复接入**。外部已接入时照旧提示。
- 标签条：`+` 新开标签页（先选要打开的 agent）、`‹ ›` 在标签多到放不下时翻动、每个标签带 `×` 关闭。
- 活动窗格边框：左上角是标题（agent 的公开 `role` 标签加名字，如 `Controller · paddock/main`；没有 role 时写 `Viewer`；shell 写 `shell · <目录>`），聚焦时边框用强调色；右下角是 `Split ▾`、`Close pane`、`Close tab`，窄时按 Saddle 的顺序省略。
- `+` 和 `Split ▾` 打开小弹框：分屏先选方向（2×2 四个方向），再从候选列表选要打开的对象；已打开的 agent 在候选里标 `Move here`；没有候选时写 `No agents to open here.`。弹框打开时只有它可以点。

## paddock 的取舍

- **shell 不再被结束**：活动窗格里是还在运行的 shell 时，从侧栏点 agent 会**新开一个标签页**放它，而不是替换 shell；活动窗格是 agent 或空窗格时，照 Saddle 放进活动窗格。shell 只在用户关闭它的窗格或标签页时结束。
- 候选列表里除了 agent，还有一项 `Shell`（在启动目录开交互 shell），这样分屏和新标签页也能开 shell。
- 每个窗格是独立的终端：各自的会话、滚动、选区、输入法。
- 分屏按比例平分；拖动分隔线调整大小可以做就做，不强求。
- 窗口顶部原来的单行标题栏去掉，改为标签条加各窗格自己的标题。
- 标签条右侧留出空地，给 P2-3 的宠物。

## 怎么算做完

- 截图（多个标签页、上下左右分屏、聚焦与未聚焦的窗格、弹框）给用户看，用户认可外观。
- 上面每条规则都能做到；关闭窗格或标签页时结束其中的会话（agent 只断开接入，不受影响）。
- 新增测试覆盖布局模型：四向分屏、关闭窗格和标签页后的活动窗格、同一 agent 只开一处、点 agent 时 shell 不被替换。现有测试照样通过；`cargo clippy --all-targets -- -D warnings` 无警告。
- 鼠标、键盘的实际操作留给用户体验。

## 不要做

- 不做布局保存与恢复、历史模式（`History` 按钮）、键盘快捷键（⌘T、⌘W 等放到 P2-4 菜单栏）。
- 不做新建 agent（New）。
- 不改 Agents 面板，除了点击接入改走新的布局规则。
- 不改 Saddle 仓库。
