## 现状（主控 10-15 查的）
- Kanban 窄面板的分组框（`kanban_view.rs`，P5-113、P5-116）：文字色 3.5% 的半透明面、12% 的边，平的。
- Cairn 的 Next session 框（`cairn_view.rs`，P5-110）：强调色 7% 的面、26% 的边，平的。
- 右侧栏卡片的底是终端底色（不透明），两个框都画在它上面。

## 要做的（照样稿「重」，两个框用同一套）
1. 一个共用的外框画法：面不透明，由终端底色混一点文字色得出（比面板亮一点）；1px 边，文字色约 12%；顶边内侧一道亮线（文字色约 12%），底边内侧一道暗线（黑色约 40%）；框外两层投影（近的小而深、远的大而散）。颜色都从主题取，换主题照样成立。
2. Kanban：窄面板展开的分组框（DONE 不加框，照旧）用它；加宽后的五列不动。行上头像状态点的圈底跟着改成新的面。
3. Cairn：Next session 的框用它，不再用强调色的面和边；框里会话之间的青绿细线照旧（用户说里面不用动）。
4. 框里的条、细线、悬停、离边距离（P5-116 的 8pt）都不动。
