## 要做的
1. **新设置 `material_opacity`**：配置文件里一个 0–100 的整数，没写时是 100（和现在一样）。读写、校验、写回照 `frame_opacity`。
2. **Settings**：General › Translucency 里，在现有两行下面加一行，界面上显示 `Material`（照现有 `Sidebar`、`Frame` 的短写法；设置全名 `Material opacity`），同一种滑块：拖动时主窗口实时跟着变，松手写进配置；改过时显示 `Reset to 100%`。界面文字用英文。
3. **画法**：整块系统磨砂按这个比例变薄：100 是现在的样子；越往下，磨砂（模糊、提亮、着色）越淡，后面的桌面越清楚；0 时磨砂完全不见，窗口在 GPUI 没画东西的地方像透明玻璃。左侧栏、右边的缝、标题栏一起变（整扇窗户一块，不分左右）。实时预览时也一样。
4. **点击不能穿透**：调到很低甚至 0 时，GPUI 没画东西的地方（缝、标题栏空白处、外框是 0 时的外框）点下去照样落在 paddock 上，标题栏照样能拖动窗口，不能漏到后面的窗口。用什么办法你定（比如磨砂或某一层保留一个看不出的最低不透明度），在完成记录里写清楚。
5. **不变的**：GPUI 画的所有东西不动——侧栏底色和它的 `sidebar_opacity`、外框和 `frame_opacity`、CLI 面板、右侧栏卡片、标签。全屏时没有磨砂、窗口不透明，照旧。磨砂的材质种类、深浅外观跟主题（`set_dark`）、常亮（P5-24b）都不变。
