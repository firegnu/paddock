## 要做的
用户 10-07 给了 GitHub 贡献图截图：“提交格子的样式能否再改一下，酷炫不足。感觉很平淡……或者你可以做的比他更好。”看过三张样稿后：“按你的推荐 C 来，派出去做吧”。

1. **实色阶梯**：五档不再是强调色加透明度，而是实色。0 档（没提交）比现在清楚，看得出是一格（样稿是底色往白混约 7%，你按主题和磨砂开关调到清楚但不抢眼）；1–4 档由深到亮：强调色混进底色（深）→ 强调色 → 白热（强调色往 `agents_text` 混，样稿约 60%）。三套预置主题下都要层次分明，相邻两档一眼分得开。图例跟着用同样的颜色。
2. **光晕**：最忙的两档带强调色光晕（样稿：第 3 档淡、第 4 档强，外加一圈很细的亮边），在磨砂和不磨砂的侧栏上都看得见、不糊成一片。
3. **对角扫光**：有提交的格子，每 7 秒左右有一道光从左上沿对角线扫到右下（每格按“列＋行”错开，一格亮起约 0.3 秒再退回），像电流流过。没有提交的格子不扫。
4. **今天那格**：光圈呼吸比现在更明显（样稿：外发光从约 4px 涨到约 14px）。
5. **动的规矩不变**：扫光、呼吸、首次弹出都只在窗口在前台时动（和现在的呼吸同一个判断），开了“减弱动态效果”时一律不动，直接显示最终样子；扫光期间只按需重画，不常驻高帧率，扫完一轮到下一轮之间不重画。
6. 只从主题取色（混色和透明度），不新增主题颜色键。
