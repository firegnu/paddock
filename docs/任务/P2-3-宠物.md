# 任务 P2-3：宠物

2026-10-05，paddock/main 自己做。
类型：功能变更
依据：DESIGN §11 第 3 项。照 Saddle 的宠物系统（`df1c727` 的 `src/mascot.rs`、`assets/pets/`、`docs/DESIGN.md` 宠物各节），用 GPUI 直接画像素图。用户 10-05：“宠物系统，我觉得如果支持图片的话，就不需要再有兼容像素的画法了，之前是因为部分terminal不支持图片的fallback方案。”

## 要做的

1. **只用图片版素材**：迁入 Saddle 的 `clawd-image.toml`、`cat-image.toml`、`capybara-image.toml`（编进程序，运行时不读磁盘），以及 `assets/pets/README.md` 中与图片版、来源、版权说明相关的部分。方块字符版素材（`clawd.toml` 等）和它的画法不迁。
2. **动画逻辑照 Saddle**：12 帧每秒；走一段（约 2.2–4.6 秒、约每秒 3 格的速度，以 Saddle 的 `step_ticks` 为准）后随机播放一个完整动作，再继续走；随机动作避开最近五种；到边先转身再返向；朝左时用 `-left` 片段，没有就按 `mirror` 左右翻转；窗口隐藏或慢帧时不补跑积压时间；位置和动作不保存。迁入 `mascot.rs` 中与图片版有关的解析和动画部分，文件开头注明来源与删减；Saddle 中对应的测试一并迁入。
3. **位置和大小**：在标签条右侧的空地上巡游，高度与标签条相称，按像素最近邻缩放、保持比例、站在底边；空地太窄时不显示。
4. **配置**：照 Saddle 的 `mascot_enabled`（默认开）和 `mascot = "clawd" | "cat" | "capybara"`（默认 clawd），写在 paddock 的配置文件里，改完重启生效。不要 Saddle 的 `mascot_display`。

## 怎么算做完

- 三只宠物都能显示、走动、转身、做动作；截图（或几帧连拍）给用户看，用户认可。
- `mascot_enabled = false` 时不显示；未知的宠物名报错并指出。
- 迁入的测试和新增的配置测试通过；现有测试照样通过；`cargo clippy --all-targets -- -D warnings` 无警告。
- 动画不明显拖慢窗口：空闲时只在宠物需要换帧时重绘。

## 不要做

- 不迁方块字符版、Kitty 图片协议、真彩色探测和 `mascot_display`。
- 不做设置页（宠物开关和种类只在配置文件里）。
- 不改宠物素材的内容。
- 不改 Saddle 仓库。

## 备注

Clawd 的图片素材取自 claude.dev 的参考（见 Saddle `assets/pets/README.md` 与 `clawd-sources.json`），是 Claude Code 的吉祥物形象；自用没问题，单独分发时是否带它待定（DESIGN §7 第 7 条）。猫和卡皮巴拉是 Saddle 原创。
