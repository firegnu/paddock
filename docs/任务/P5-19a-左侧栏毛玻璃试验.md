## 要做的
1. **主窗口开模糊**：主窗口用 `WindowBackgroundAppearance::Blurred`。New Agent、设置、About 这些独立小窗口不变。
2. **半透明的是“窗口底”**：现在用 `agents_bg` 铺的整片底——左侧栏（展开和收起后的窄条）、标题栏、窗格卡片之间和四周的缝——改成半透明，后面的桌面模糊透出。
3. **侧栏里的东西跟着透**：侧栏 agent 卡片、展开后的小格、选中底、悬停底、等你的琥珀底、分组头这些叠在侧栏上的底色，改成半透明，叠在玻璃上仍分得出层次；文字、图标、状态色照旧清楚。
4. **保持不透明**：终端窗格卡片（含分屏标题）、右侧栏卡片、窗口内弹出框（新标签、分屏、Attention、palette、悬停说明、确认框）、拖动时的遮罩，都和现在一样不透明。
5. **三套主题各定不透明度**：dune、tide、lagoon 各自定窗口底和侧栏卡片的不透明度，文字在浅色和深色桌面背景上都读得清。数值放在代码里（每套主题一组），不新增配置项、不新增 `[colors]` 颜色键；用户在 `[colors]` 里改了 `agents_bg` 的，照样按这套不透明度透。
6. **全屏退回不透明**：进入全屏时窗口切回 `Opaque`、底色不透明度回到 1，样子和现在一模一样；退出全屏再切回模糊。
