## 要做的（照样稿；颜色一律从主题取，样稿上的色值只是示意）
1. **配置**：`[[machines]]` 每条多两个可选键：
   - `label`：显示名，任意文字（去掉首尾空白后不为空、不含控制字符；长度上限你定一个合理的）。没写就显示 `name`。
   - `show`：`false` 是藏起来；没写或 `true` 是显示。放回来时删掉这一行，不写 `show = true`。
   - `name` 照旧是身份（保存的窗格布局按它记），规则不变，界面上不改它。
2. **甲 Settings › Machines**：Settings 左边新开一页 `Machines`，排在 Agents 后面。每台一行：状态点、显示名、ssh 目标（设了 `label` 时后面小字写 `id <name>`）、状态（`Online · <n> agents`；连接中、连不上照切换栏的短状态；藏起来的写 `Hidden`）、`Show` 开关、`Remove…`。页头一句说明、页底一句“加机器照旧手写 `config.toml`”，用样稿原文。一台都没配时，这一页写明没有、怎么加。
3. **戊 改名**：在那一行点显示名就地变成输入框：Return 存（写 `label`），Esc 取消，清空再存就删掉 `label`、回到 `name`。显示名用在所有现在把机器名写给人看的地方：切换栏胶囊、窗格的机器小签、名字签、收件箱、读不到的横幅、停和暂停的确认框、右侧栏说明卡、只在本机的提示卡。身份、布局、连接一律照旧用 `name`。显示名太长时胶囊里截断加省略号，悬停说明写全名。两台显示名一样时照样存，那一行写一句提示。
4. **丙 胶囊上右键**：远程机器的胶囊上右键出菜单：`Rename…`（打开 Settings › Machines，那一行直接进改名）、`Hide <显示名>`、`Remove <显示名>…`（同乙的确认）、分隔线、`Machines Settings…`。`This Mac` 那颗右键没有菜单。
5. **丁 藏起来 = 当成没配**：不连 ssh、不读，切换栏、收件箱、铃铛里都没有它；它保存的窗格布局留着，放回来照常恢复。正显示着它时先切回 This Mac。全都藏起来时切换栏整条不画，和没配远程一样。
6. **乙 删掉**：`Remove…` 先出确认（样稿 `B-Remove` 的文字，三个按钮 `Hide instead`、`Cancel`、`Remove`）。确认后：从 `config.toml` 删掉那条 `[[machines]]`（别的内容、注释照旧），关掉它开着的窗格，忘掉它保存的窗格布局，断开连接；正显示着它时先切回 This Mac。不碰那台机器上的任何东西。
7. **立即生效**：从 paddock 里改名、藏、放回、删，都立即生效，不用重开。写 `config.toml` 沿用 Settings 现有的写法（保留注释和别的键；写之前文件被别处改过时不覆盖；出错时提示）。手改 `config.toml` 里的机器要不要立即生效不在这一件里，照现在的做法。
8. 不加 `Add machine…`。

### 拿主意的地方
- `label` 上限 40 个字符；改名写回 `name` 本身也当作删掉 `label`。
- 改名框点别处（失去焦点）也存，同 workspace 改名。
- 删除确认用 Settings 窗口里的自绘确认框（同 Integrations 的），不用系统对话框，为了红色 `Remove` 和三个按钮；胶囊上的 `Rename…`、`Remove…` 都打开 Settings › Machines 再做，`Hide` 在胶囊菜单里直接做。
- 已藏起来的机器删除时，确认框不出 `Hide instead` 和那句“hide it instead”。
- “文件被别处改过时不覆盖”做成：每次都读文件现在的样子、只改那一个键，别处的改动留着；那台在文件里已经没了就不写并提示。没有沿用 Settings 页“和上次读到的不同就停下问”的做法，因为这里只动一个键、不会盖掉别的。
- 拆下连接时发 `ssh -O exit` 关本机的 ControlMaster（只和本机 socket 说话），否则主连接会在后台留到 ControlPersist 到期。
- 手加进 `config.toml`、还没接上的机器状态写 `Connects after a restart`（手改照现在的做法重开生效）。
- 配置里机器写错时，Machines 页底下也用红字写出 `machines_problem`。
- 胶囊菜单行只有字，没配图标（样稿没有图标）；Machines 页图标自画了一个显示器。

### 没做的事
- 手改 `config.toml` 里的机器不立即生效（照任务说的，照现在的做法）。
- 改名后已经写进窗格的一次性提示（`Connecting to …`、`Lost connection to …`）到下次刷新才换成新名字。
- 没加 `Add machine…`；没改连接、重连、attach、只读判断和 `name` 的规则。

### 踩过的坑
- toml 类型错（如 `label = 3`）时 serde 的报错不带键名，先加一步 `typed()` 按键检查类型再反序列化。
- `TextInput::select_all` 不公开，改名框不全选，同 workspace 改名。
- 两个窗口互相更新会因实体正在更新而 panic，所有改动都经 `App::defer` 再走 `windows::edit_machine`。
- 原来侧栏订阅时把座位号捕获在闭包里，座位能挪动后会错位，改为事件到时按侧栏实体找座位。
