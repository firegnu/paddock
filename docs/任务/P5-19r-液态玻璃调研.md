结论：公开 raw-window-handle 通路能取得 GPUI NSView、NSWindow 和 contentView，paddock 现有 announce 代码已使用它；局部玻璃兄弟视图的插入与几何同步在接口层面可行，但运行效果未验证。Apple 建议让内容成为玻璃的 contentView，避免兄弟视图垫底；当前侧栏和终端共享一个原生绘制视图，因此不能直接确认这种接法足以交付原生侧栏玻璃。objc2-app-kit 0.3.2 已在锁文件中且有玻璃声明，无需为接口升级 GPUI。
