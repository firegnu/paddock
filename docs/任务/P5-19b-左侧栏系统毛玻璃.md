## 要做的
1. **只有左边一列是毛玻璃，从最上面到最下面**：左侧栏（展开时）或收起后的窄条，连同它正上方那段标题栏（红绿灯、收起图标、Agents、铃铛那一段），从窗口最上沿（红绿灯那一行）到最下沿，整列后面都是系统模糊，中间不夹不透明的横条。侧栏拖宽、收起展开、改字号、窗口缩放时，这一块跟着对齐，不留缝、不盖到右边。
2. **右边恢复原样**：标题栏右边（标签、`+`、分屏、搜索、右侧栏按钮及它们的高亮）、窗格卡片之间和四周的缝、终端、右侧栏、弹出框，都恢复成 P5-19a 之前的不透明样子。
3. **系统材质**：用 `NSVisualEffectView`，侧栏材质（`.sidebar`），透过窗口后面（`behindWindow`），保留系统的磨砂、提亮和饱和度，不像 GPUI 那样去掉。视图放在 GPUI 内容下面，只用来显示，不接鼠标键盘事件。材质的深浅外观跟主题走（三套主题都是深色就用深色外观）。窗口在后台时跟系统侧栏一样变淡，照系统默认。
4. **侧栏上的颜色**：侧栏这一块 GPUI 画的底色改成很淡的主题色罩（或不画），让磨砂透出来；卡片、选中、悬停、等你的琥珀底、小格、按钮底是半透明叠在上面，层次和文字仍清楚。三套主题各定数值，放在代码里，不新增配置项和 `[colors]` 键。P5-19a 加的、现在用不上的东西删掉。
5. **全屏退回不透明**：全屏时隐藏这个视图，窗口切回不透明，样子和 P5-19a 之前一样；退出全屏恢复。
6. **稳**：AppKit 调用都在主线程；视图的所有权清楚，窗口关闭、重开窗口不崩溃不泄漏；拿不到 `NSView` 或建视图失败时退回不透明，照常能用。
