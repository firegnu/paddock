## 现在是怎样（主控 10-20 核对的）
- 程序发的进度信号 OSC 9;4（`ESC ] 9 ; 4 ; <状态> ; <百分比> BEL`：状态 0 清掉、1 设百分比、2 出错、3 不知道多久、4 暂停）paddock 收到后忽略。
- 谁会发：Claude Code（2.1.303）有这个功能且默认开，但只在 `TERM_PROGRAM` 是 Ghostty ≥1.2 或 iTerm ≥3.6.6（或 ConEmu）时发；paddock 不设 `TERM_PROGRAM`，所以从 paddock 开的 Claude Code 一般不发，从 Ghostty 开、再在 paddock 里看的可能会发（未实测）。Codex（0.163.0）不支持。用户 10-20 知道这点后仍要做。
- 响铃：`terminal.rs` 把 BEL 交给 alacritty，alacritty 发出的 Bell 事件 paddock 不处理，界面上什么都没有。
- 窗格头部在 `window.rs`（`pane_header`）；标签胶囊上已有状态记号和“有 agent 等人”的琥珀圈（`window.rs` 里 capsule 一带）。

## 要做的（照样稿，用户选的）
1. **终端层接住进度**：解析 OSC 9;4，记下每个会话现在的进度（没有／百分比／不知道多久／出错／暂停），变化时告诉窗口（事件或可读的状态，终端层不认识窗口）。程序退出、会话换掉时清掉。
2. **进度条（4A）**：窗格头部底边一条 2 px 的线，主题强调色；百分比时按比例填，变化时平滑过去；不知道多久时一段约 28% 宽的光从左往右慢慢滑（约 1.5 s 一趟）；出错时变成危险色；清掉（做完）时先填满再淡掉。
3. **标签胶囊上也显示（“加胶囊”）**：这个标签页里有窗格在报进度时，标签胶囊上一个小圆环跟着走（不知道多久时转圈，出错时变色，做完淡掉）；和已有的琥珀圈、状态记号不打架。
4. **响铃（5 都要）**：程序响铃时，(A) 这个窗格边缘泛起一圈淡琥珀光，约 0.45 s 淡掉；(B) 窗格头部一个小铃铛晃一下，标签胶囊上出现一个琥珀小点，过一会儿（约 2.5 s）淡掉。不发声，不闪整个屏幕。
5. **不动的时候不要帧**：进度条只在滑动、过渡时要帧，静止的百分比、没有进度、响铃淡完之后都不要帧、不留定时器。系统“减弱动态效果”时：不知道多久的那段光不滑（改成一条静止的淡线），铃铛不晃。
