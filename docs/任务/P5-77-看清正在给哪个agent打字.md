## 要做的（照样稿 `B-Pill.dc.html`）
1. **名字签**：窗口里当前窗格（键盘输入去的那个）显示的是 agent 时，在它的终端区域上叠一枚小签。
   - 平时：很淡，只有种类图标（半透明）和 agent 的完整名字（如 `paddock/main`）；约 22pt 高的胶囊，底色取终端背景，细边是文字色的一成多，字用界面字体、约 11pt（随界面字号缩放），淡色。
   - 亮起：底色是强调色淡淡地盖在终端背景上，边是强调色，带一点投影；内容是强调色的 `To`、种类图标、粗体亮色的名字，后面跟 `· 会话题目`（`session_topic` 的结果；没有题目就只有名字）。太宽时题目用 “…” 截，名字始终完整，整枚不超出终端区域。
   - 强调色、淡色、亮色都从主题现有的颜色里取（选中卡片、标签用的那一套），七套主题都要分得清。
2. **什么时候亮**：这个窗格已经 10 秒以上没有打字，再打下第一个字的那一刻亮起，保持约 1 秒，再用约 0.4 秒淡回平时的样子。接着连续打字不再亮；每个窗格各算各的。
   - 算“打字”的：会把字送进程序的按键（字母、数字、符号、空格）、输入法开始组字和上屏、粘贴。
   - 不算的：只按修饰键、带 ⌘ 的快捷键、方向键、功能键、单独的回车／Esc／Tab／退格，鼠标操作，程序自己的输出。
3. **放在哪**：paddock 看不到程序画的输入框，只知道终端光标在哪一格。名字签贴着终端区域的右边（留约 10pt），竖直方向居中在光标所在行的上一行（Claude Code 单行输入时正好骑在输入框的上边框上，和样稿一致）。光标在第一行、或者光标所在行不在画面里（往回翻看历史时），放在终端区域的右下角。光标换行时名字签跟着走。
4. **不碍事**：名字签不接鼠标（点击、拖选、滚动照旧落到终端上），不改终端的行数列数，不拦任何按键。
5. **哪些窗格没有**：shell 窗格、空窗格、不是当前窗格的窗格、agent 已经不在的窗格。窗口不在前台时照平时的样子画，不亮。
