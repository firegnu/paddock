## 要做的

1. **预置主题**：`theme = "dune" | "tide" | "lagoon"`，不写等于 dune。
   - 界面颜色从 `saddle::theme::Preset` 取，不复制色值。
   - Saddle 的 `terminal` 主题本轮不提供：写了就报错，说明不支持。在完成记录里给一个处理建议（不提供，或者怎么对应），由用户定。
   - 未知的主题名报错。

2. **每套主题的终端配色**：16 个基本色，加上默认字色、默认底色、光标色、选区色。
   - 默认字色和底色与该主题的 Saddle `text`、`bg` 一致。Saddle 中为 `Reset` 的（如 Dune），由你定具体颜色。
   - 用户的问题是“深蓝在深色底上看不清”。规则：除 0 号（黑）以外，15 个基本色在本主题默认底色上的对比度都不低于 3:1。
   - 选区改成用选区色画底，不再把字色和底色对调。
   - 256 色立方、灰阶、程序直接给 RGB、程序用 OSC 4 改调色板，这些现有行为保持不变。
   - 参考现成配色方案时，核对来源和许可，在代码注释里写明出处。

3. **`[colors]` 覆盖**：最终颜色＝预置主题＋覆盖。
   - 可覆盖的键：Saddle 的 41 个界面颜色名（与 Saddle 同名），加上终端配色的 20 个键。终端配色的键名由你定，沿用 Saddle 的风格（小写、下划线），写进 `app/README.md`。
   - 颜色值的写法用 `saddle::theme::parse_color` 解析，与 Saddle 一致。
   - 未知的键、写错的值都报错，报错里带上键名。

4. **先出调色板给用户批准，再写定**：
   - 三套主题各截一张图，用 `app/samples/render.ans`，按 AGENTS.md 只截本窗口，存到本机临时目录，不入库。
   - 每套附一张 16 色＋前景、底色、光标、选区的色值表，以及每个色在底色上的对比度。
