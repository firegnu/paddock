## 要做的
用户原话：“我的要求就是优雅。还是优雅。”；“方向没问题，按区域拆活派出去吧，活一定要细，要优雅。你的方案没问题”。按 `Cards.dc.html`、`Main.dc.html` 做：

1. **卡片两行，比例字体**（去掉现在等宽字体的多行详情）：
   - 第一行：状态圆点（8pt）、名字（13，选中时 600，否则 500）、种类小字（11，`claude`、`codex` 等用主题里对应的颜色）、右侧时长（11.5，淡色，等宽数字）。
   - 第二行（12，缩进对齐名字）：平时是目录（家目录缩成 `~`，太长时中间省略，如 `~/…/paddock`）和分支，用 `·` 隔开；没有 git 信息时只写目录，不写 “git unavailable”。等你回复时改成琥珀色的说明（“等你回复”；corral 的 `title` 有内容时可以接在后面）；出错或已退出时改成红色的一句（如 “已退出（退出码 1）”）；启动中写 “启动中…”。
   - 现在的 `ERR …`、`ATT`、`VIA`、实例号这些行都不再平铺在卡片上。
2. **状态圆点的颜色**：工作中、空闲、等待、卡住、出错、启动中各用主题里已有的 agent 状态色；工作中轻微呼吸。不再写 `idle`、`working` 这类状态文字（展开详情里可以写中文说明）。
3. **展开详情**：点一下卡片照旧打开这个 agent；**再点一次已经打开的那张**才展开或收起它的详情（第二行下方，一条淡线隔开，两列 “标签 值”，11.5）：目录全路径、分支（含改动数、领先落后）、模型和强度（来自标签）、接入（几个窗口）、上次输入（谁、多久前）、实例号（等宽小字）。底部的“折叠”按钮改为收起所有展开的详情。原来“当前窗格的那张总是展开”的规则去掉，卡片默认都是两行。
4. **选中**：当前窗格显示的那张用浅色圆角底（主题的选中底色），不用竖线；悬停时有更淡的底。
5. **分组头**：小号大写的组名（10.5、600、字距约 0.08em、淡色）后面跟数量（更淡），不画横线、不用强调色。没有前缀的 agent 组名照旧。
6. **头部**：“Agents” 用 15/600，后面跟总数（12、淡色）。有需要处理的 agent 时，右侧出现一个小徽标（铃铛图标加数字，琥珀色字、琥珀色浅底、圆角胶囊），点它照旧打开 Attention 列表；没有时不显示。
7. **空状态**：没有任何 agent 时，列表区居中显示一个淡色的加号图标、“还没有 agent”、一句说明（“新建一个，在这里看它的状态和回复。”）和一个“新建 agent”按钮（点它和底部的新建 agent 一样）。读不到 corral 时照旧显示错误说明，但用同样安静的排版。
8. 窄侧栏和大字号下：名字过长时省略，时长和种类不被挤掉；第二行单行省略。
