2. 退出（⌘Q、关主窗口）时，若有活着的 shell，同样先问（在 P3-2 的设置窗口询问之后）；Cancel 不退出。
3. 回答前布局变了（比如那个窗格自己已经关了），按回答时的情况处理，不关错。
