## 现在是怎样（主控 10-20 核对的）
- 终端里写剪贴板只有两处：⌘C（`app/src/view.rs` 的 `copy`）和工具条的 `Copy`（`copy_selection`）。shell 窗格和 agent 窗格是同一个 `TerminalView`，行为一样。
- 鼠标选中松开时，`view.rs` 里有一处判断“这次松开结束了一次鼠标选区、选区不空”，交给工具条 `self.toolbar.let_go(ended, rows.is_some(), …)`（约 1025 行）。
- 设置项的现成写法：`smooth_scroll`（P5-143c2）从 `config.rs`（字段和默认值）、`settings.rs`（`field(...)`、读写、测试）、`settings_view.rs`、`main.rs`（`Options`）、`window.rs`（改了设置后推给每个终端 `set_smooth_scroll`）一路接到 `view.rs`。Settings › General 里终端那一组有 `Animate cursor movement`、`Smooth scrolling`、`Keep text legible`。

## 要做的
1. Settings › General 终端那一组加一个开关 `Copy on select`，默认关；存进配置，和 `smooth_scroll` 一样改了立即对所有已开的终端生效。
2. 打开时：用鼠标选中（拖选、双击、三击，程序要了鼠标时按住 ⇧ 选的也算）松开、选区不空，就把选中的文字写进剪贴板，和 ⌘C 复制的内容一样。工具条照常出现。
3. 关着时行为和现在完全一样。
4. 不是鼠标选区结束的松开（报给程序的点击、⌘ 点链接、单击取消选区）不复制。
5. `docs/DESIGN.md` 终端那一节补一条。
