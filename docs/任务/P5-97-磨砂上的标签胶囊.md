## 现在是怎样
标题栏的标签是胶囊：底色是侧栏底色叠一点文字色（或状态色），不透明；选中的更亮、带彩色圈；没选中的悬停时 `×` 浮在标题末尾，靠不透明的底把下面的字挡住。`+N` 同样。

## 要做的
1. 磨砂时，没选中的标签改成侧栏 agent 卡片那样的半透明面（文字色的淡色，状态色的照旧带一点状态色），加一圈很淡的边；悬停亮一点。
2. 选中的标签同样半透明，比没选中的亮一档，彩色圈照旧。
3. 没选中的标签悬停出 `×` 时，`×` 不叠在透出的字上：标题给 `×` 让出位置（截短），`×` 自己的圆底照旧。
4. `+N` 跟没选中的标签一样。
5. 全屏照旧不透明，样子和现在一样。

## 怎么算做完
- 用户：“没被选中的tab看起来稍微有点丑。”“两件都按你的建议做。”
- 自查：`app/` 下 `cargo test --all-targets`、`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 通过；胶囊底色的取法放在不依赖 GPUI 的函数里，先写测试看它失败再实现。
- 装上给用户看。

## 不要做
- 不改标签的大小、字、图标、彩色圈的规则；不改右侧栏里的胶囊（在卡片里，不透明的底上）。
- 不起测试窗口、不截图。
