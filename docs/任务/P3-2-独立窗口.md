# 任务 P3-2：设置与 About 改为独立窗口

2026-10-05，paddock/main 自己做。
类型：功能变更
依据：DESIGN §12「窗口与对话框按 macOS 做」和第 2 项。用户 10-05：“没必要复刻tui的esc关闭，gpui有窗口啊”；关窗时有未保存改动“按1”（保留草稿和 Save，关窗时问 Save / Don't Save / Cancel）；“设置窗口按照你的意见做”。这一批不逐件等回复，做完一并汇报。

## 要做的

1. **设置窗口**：⌘,（或菜单 Settings…）打开一个单独的 Settings 窗口；已开着就提到最前。内容、编辑规则、保存规则和 P3-1 相同（左边页面、右边设置项、草稿、Default、换主题、报错、文件被外部改过时的 Keep / Discard）。
   - 关闭：红点或 ⌘W。没有未保存的改动直接关；有的话弹系统提示框 Save / Don't Save / Cancel。Save 成功才关；失败（写错的值、文件被外部改过）时窗口留着，原因照常显示在底部。
   - 不再用 Esc 关闭或取消。底部的 Cancel 改为 Revert（放弃草稿、窗口不关，没有改动时不可用）；Save（⌘S）照旧。
   - 保存后主题、颜色、侧栏宽度、宠物照旧立即作用到主窗口；设置窗口自己也换成新主题。
2. **About 窗口**：菜单 About paddock 打开一个小窗口（版本、说明、来源，内容同现在的弹框），红点或 ⌘W 关闭；已开着就提到最前。
3. **退出**：⌘Q 或关主窗口时，设置窗口有未保存的改动就先把它提到最前、同样问 Save / Don't Save / Cancel；Cancel 则不退出。关掉设置、About 窗口不退出程序（现在任何窗口关掉都会退出）。
4. 截图只截本程序的窗口：设置窗口也照 `GPUI_TERM_WINDOW_ID` 打印窗口编号。

## 怎么算做完

- 用户原话：“没必要复刻tui的esc关闭，gpui有窗口啊”；“按1”。
- 现有测试照样通过；`cargo clippy --all-targets -- -D warnings` 无警告。
- 截图（设置窗口、About 窗口）留到这一批做完一并给用户看；红点、⌘W、提示框的实际操作留给用户体验。

## 不要做

- 不改设置项本身和保存规则。
- 新标签、分屏的弹出选择保持现状（DESIGN §12：菜单一类仍可 Esc 收起）。
- 关闭运行中 shell 的确认是 P3-3，这里不做。
- 不改 Saddle 仓库。
