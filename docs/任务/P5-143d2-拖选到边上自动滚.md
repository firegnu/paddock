## 现在是怎样（主控 10-19 对着代码核对的）
- 拖选：`view.rs` 的 `mouse_down`／`mouse_move`／`window_move`／`window_up`，状态在 `view/press.rs` 的 `Mouse`。拖出窗格时 `locate` → `grid::cell_at` 把位置夹到最上或最下一行，所以选区停在边上那一行，不会滚。
- 滚动：P5-143c2 后回看历史按像素（`view/glide.rs`：`Glide::drag` 立即走、`Glide::wheel` 缓动），整行由 alacritty 的 `display_offset` 管；Settings 的 `Smooth scrolling` 关掉时按行滚。
- 拖着不动时没有鼠标事件：要靠定时器或每帧继续滚。

## 要做的
1. 拖选时鼠标在格子区域上边之外：视野往更早的历史滚；下边之外：往更新的滚（到底停）。离边越远滚得越快（有上限）；鼠标回到格子区域里就停。
2. 鼠标拖着不动也一直滚，选区的一端跟着滚进来的那一行走，松开就停。
3. 用平滑滚动的那套（`Smooth scrolling` 开时按像素走，关时按行走）；滚到顶或底停住。
4. 只在拖选时滚：程序要了鼠标、按着 ⌘ 点链接（`Press::Link`）、全屏程序（alt screen，没有历史）时不滚；左右拖出窗格照旧，不滚。
5. 不在拖时不留定时器、不要帧（P5-143a、c1、c2 的省 CPU 不能丢）；窗口失去前台或按下被取消时立即停。
