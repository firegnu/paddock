## 要做的（主控提的，用户 10-20 同意；问过的几处用户都选了主控推荐的）
1. **回看历史时的位置条**：滚到历史里时，窗格右边浮出一条细的位置条，标出现在看的是整段历史里的哪一截；停止滚动后一会儿淡出。在底部不显示；alt screen（vim、less 等）不显示。只是标示，不用来拖。
2. **“有新输出”提示**：滚在历史里时底下来了新输出，窗格下方出现一个小胶囊 “↓ New output”；点它回到底部，自己滚回底部时消失。
3. **查找标出全部结果，带计数**：查找栏开着时，可见范围里的其他匹配用淡一些的黄色标出（同 P5-143d3 的圆角半透明画法，比当前结果更淡）；当前结果照旧亮黄。查找栏显示 “当前第几个/一共几个”（如 `3/17`，按整段历史数；没找到照旧显示没找到）。跳转规则（⌘G、⌘⇧G、回车）不变。
4. **⌘+／⌘-／⌘0 调字号**：所有终端窗格一起变大变小（用户选的）；不改 Settings 里的字号，⌘0 回到 Settings 的字号，重开 paddock 也回到它；有上下限。
5. **自动保证字看得清（最小对比度）**：字色和它所在格子的底色对比度太低（约低于 3:1）时，把字色往看得清的方向调，正常配色不受影响；默认开，Settings 里能关（用户选的）。
6. **改窗格大小时显示行列数**：拖窗格分割线、改窗口大小时，窗格中间显示 `120×40` 一类的小标签，停下后一会儿淡出；刚开窗口、刚开窗格时不显示。
