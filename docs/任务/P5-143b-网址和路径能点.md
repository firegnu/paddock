## 现在是怎样（主控 10-19 对着代码核对的）
- 终端窗格的鼠标在 `app/src/view.rs`：`mouse_down`／`mouse_move`／`mouse_up`（约 1033–1100 行）。程序要了鼠标（vim、less 等）时报给程序，按住 ⇧ 时改为选择；否则按下开始选择，双击选词、三击选行。没有任何链接的认法和画法。
- 网址、路径都不能点。程序用 OSC 8 标的链接，alacritty 已记在格子上（`Cell::hyperlink()`），paddock 没用。
- 右侧栏 Browser 打开网址已有现成做法：`window_ctl.rs` 的 `Plan::Browse`（打开右侧栏、切到 Browser、`BrowserView::visit(url)`）。
- 窗格知道自己的目录：shell 窗格是开 shell 时的目录（`TerminalView::cwd`，不跟着 `cd` 变：paddock 不读 OSC 7）；agent 窗格是 agent 的 `cwd`。远程 agent（5090）的窗格，路径指的是远端的文件。
- alacritty_terminal 0.26 自带按正则在格子里找文字（`term::search::RegexSearch`、`RegexIter`，基于已在锁文件里的 `regex-automata`），能跨换行折断的行找。

## 要做的
1. **认出来**：
   - 网址：`http://`、`https://` 开头的（结尾的标点、不配对的右括号不算进去）。
   - 文件路径：绝对路径、`~/` 开头、`./`／`../` 开头，以及带 `/` 的相对路径；可带 `:行` 或 `:行:列`。相对路径按窗格的目录（上面那条）解析；**文件确实存在才算链接**，不存在就不画、不点（避免把普通文字当路径）。
   - 程序用 OSC 8 标的链接照它标的地址认，优先于上面两种。
   - 只在按住 ⌘ 时去认鼠标下那一处，不对整屏常驻扫描。
2. **样子**：按住 ⌘ 悬停到链接上，整段链接（含折到下一行的部分）加下划线、指针变手；松开 ⌘ 或移开就恢复。不按 ⌘ 时什么都不变。
3. **打开**：⌘ 点击。
   - 网址在右侧栏 Browser 打开（照 `Plan::Browse` 的做法）。
   - 文件路径：照下面「打开文件（用户定的甲）」。
   - 远程 agent 窗格：网址照常；文件路径不认（远端的文件本机打不开）。
4. **不误触**：不按 ⌘ 时，点击、拖选、双击、三击和现在一样；程序要了鼠标时，不按 ⌘ 照旧报给程序，按 ⌘ 点在链接上才打开、不报给程序。⌘ 加拖动仍是选择（不打开）。

## 打开文件（用户 10-19 定甲）
- Settings 里加一项“用什么打开文件”（配置文件里一个字符串键，名字由开发定、写进完成记录；Settings 页照已有的 `Kind::Text` 字段加）。界面文字用英文。
- 空（默认）：用 macOS 的 `open <路径>`，系统给这类文件配的程序打开，不跳行。
- 填了命令（如 `zed`、`code -g`、`cursor -g`）：按空白拆成程序和参数（不经 shell），后面接 `路径:行:列`（没有行列就只接路径），能跳到那一行。
- 打开失败（命令不存在、退出码非 0）要让用户看得见（照 paddock 现有的出错提示方式），不能悄悄没反应。
- 找命令用 paddock 自己的 `PATH`（`main.rs` 启动时已从登录 shell 取来，从程序坞打开也找得到 `~/.local/bin` 等处的命令）。
- 乙（先找 Changes）、丙（Finder 里显示）用户没选，不做。
