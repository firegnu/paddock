# 任务：看板卡片收紧：一栏一个框，条间细线

依据：用户 10-15 发来看板截图：“现在的卡片给人感觉太空了。重新设计一下”。主控查到编号、标题、记号各占一行，只有一个 Draft 的卡片也是三行高，DONE 里一行和大卡片混着；出样稿甲（卡片收紧）、乙（一栏一个框），用户：“选乙。我喜欢乙”。
执行：主控

## 现状（主控 10-15 查的，`app/src/kanban_view.rs`）
- `card()`：每件活一张卡片（P5-71），第一行编号小标签和时间、第二行起标题、再一行记号胶囊（Draft、High、Low、Waits for、Dropped），等你的再一块淡琥珀底；在做、待审、已合并的底部一道细线隔出 agent 一行。
- `done_row()`：DONE 里普通的是一行；等你的、Dropped 的仍走 `card()`，是大卡片。
- `asks()`：Needs you 那段最多两行，交给 GPUI 截。截图里 P5-90 第二行右边被切掉、没有 `…`。
- 窄面板 `list()` 和加宽后五列 `columns()` 共用 `card()`；五列每列本来就是一个框。

## 要做的（照样稿乙）
1. **一栏一个框**（窄面板）：每个分组展开后，它的活放进一个框（文字色约 3.5% 的面、7% 的细边、圆角 10），条与条之间一道细线，不再一件一张卡片、不再有亮线暗线。鼠标在一条上时那条整条一层淡底，它上下的细线不画。加宽后五列：每列本来就是框，里面照样是条和细线，不再套一层框。
2. **一条的排法**：左边一栏编号（等宽小字、淡色，宽度固定，标题对齐），右边标题（最多两行，长了 `…`，粗细照旧），最右边时间和记号。标题下面再有的东西（Needs you、Waits for、agent 一行）都从标题的左边缘起排，不再顶到最左。
3. **草稿**：不再有虚线边框和 Draft 胶囊；编号前画一个虚线小圈（悬停说明 Draft），标题淡一些。
4. **优先级**：High、Low 不再写胶囊，只用左边那道色标（High 红、Low 淡，照旧）。
5. **Waits for**：从胶囊改成标题下一行，链接符号加字，小字、淡色。
6. **Needs you**：标题下一行，粗体琥珀色 “Needs you” 后面跟 `待用户：` 的内容，**一行**，长了由 paddock 量宽度截、加 `…`（修好截图里右边被切、没有 `…` 的问题）；鼠标放上去悬停说明写全文。不再有淡琥珀底块；那条也不再有琥珀边和琥珀面（框里是条，不是卡片），顶上 “N need you” 照旧。
7. **在做、待审、已合并**：agent 一行（和待审的主控一行）放在标题下面，不再用细线隔出底部；内容、截法和悬停时时间挪到这一行末尾照旧。
8. **DONE**：一律一行，不加框：编号、标题、时间；Dropped 的标题淡一些，时间前写 Dropped（细边小胶囊，悬停写原因，照旧）；等你的那条下面加第 6 条的 Needs you 一行。Show all 照旧。
9. **照旧不动的**：悬停时右上角小底托放按钮（时间让给它）；Clear、Set priority、Delete、Drop 的就地确认照旧在那一条里；格式警告在编号旁；折叠的分组照旧露出等你的那几条；点一条的行为、分组标题、顶部都不变。
