## 要做的

**顶行（跟着焦点时，样稿 1）**
- 文件夹图标、仓库名、一个小箭头合成一个按钮（悬停有底色），点了开菜单。
- 其余不变：`main` 小标、概况（`Nothing in progress` 等）、New task。

**菜单（样稿 2）**
- 弹在仓库名按钮正下方，左对齐；点外面或按 Esc 关掉。
- 第一行 `Follow focused pane`，右边淡色写焦点窗格所在仓库的名字（没有就不写）。跟着焦点时这一行打勾。
- `Open now` 一段：paddock 里现在开着的仓库。
  - 左侧栏每个 agent 所在的仓库，加上开着的 shell 窗格所在的仓库。worktree、子目录都算进主仓库（和 P5-80 的分组一个读法）。
  - 按名字排，同一个仓库只列一次；不在 Git 仓库里的不列；已经在 Kept 里的不在这里重复。
  - 没有可列的就不画这一段。
- `Kept` 一段：选过的仓库。每行前面一个图钉图标，悬停时行尾出一个 ×（提示 `Remove from this list`）。没有就不画这一段。
- 不跟焦点时，正在看的那个仓库那一行打勾。
- 每行悬停的提示写完整路径（两个同名的仓库靠它分）。
- 读“哪个目录属于哪个仓库”在后台做，不在画界面的线程里跑 git。

**选了之后（样稿 3）**
- 点 `Open now` 或 `Kept` 里的一行：看板改看那个仓库，不再跟焦点；这个仓库记进 Kept（已经在就不重复）。
- 点 `Follow focused pane`：回到跟焦点。
- 点 ×：把这个仓库从 Kept 移掉。移的正是在看的那个，看板同时回到跟焦点。
- 不跟焦点时顶行的样子：
  - 仓库名按钮带强调色的淡底和细边，文件夹图标换成图钉。
  - 原来写概况的位置换成 `Back to <名字>` 按钮，名字是焦点窗格所在的仓库；点了回到跟焦点。没有焦点窗格、焦点窗格不在仓库里、或它就是正在看的这个仓库时，按钮写 `Follow focus`。
  - 放不下时仓库名先省略；这个按钮和 New task 不缩。
- 只切看板。Changes、Browser、Cairn、左侧栏、标题栏、终端都不变，焦点不动。
- 看板上的动作都落在显示的那个仓库上：New task、Edit、Set priority、Clear、Open task file。
- Go to agent、Show changes 照旧把那个 agent 的窗格带到前面；看板仍停在选的仓库上。

**没东西可看时也要能切**
- 现在这几种情形只画一句说明、不画顶行：`No pane in focus`、`Not in a repository`、`No main branch`、`No task files`、`Git couldn't be read`。
- 改成这几种情形也画仓库按钮（读得出名字写名字，读不出写 `No repository`），菜单照常能开。不然没有焦点窗格时，没法切到 Kept 里的仓库。
- 不跟焦点时，说明文字里不提 focused pane（选的目录已经不是仓库时，说明要对得上）。

**菜单最下面一行 `Choose folder…`**
- 弹系统的选文件夹窗口（New Agent 里已经在用）；选的目录所在的仓库进 Kept，看板切过去。选的目录不在 Git 仓库里：不加，就地说明。

**记住什么**
- Kept 列表存在本机，和布局文件放在一起（`kanban-repos.json`，照 `activity.rs` 存仓库列表的写法：只存路径，读的时候目录已经不存在的跳过）。不进仓库，不进设置页。

## 用户定了的（10-11：“都按你的建议来”“样稿可以”）
1. 入口是看板顶上的仓库名，点了弹菜单；菜单三段：`Follow focused pane`、`Open now`、`Kept`。
2. 选过的仓库留在菜单里，直到手动移掉。带来的结果：只是点开看一眼别的仓库，也会在 Kept 里留下一行，要自己点 × 清。
3. 只切看板，Changes、Cairn 照旧跟焦点。
4. 切走之后有明显的记号，一下能回到跟焦点；`Back to …` 按钮占掉概况文字的位置（样稿 3，主控 10-11 说明过切走时看不到概况）。
5. 这是 paddock 的通用功能：看板能看任何一个仓库。paddock 里不加“家”“想法仓库”这类概念，不认任何特定的仓库名。

## 主控想加、问过用户的（10-11：“接受你的建议”）
样稿上没有或看不出来，是主控的主意，用户五处都同意：
1. **`Choose folder…`**。没有它，一个没开任何窗格的仓库要先在里面开一次窗格、从 `Open now` 里点一次，才进得了 Kept。建议加。
2. **重开后回到跟焦点**，只留 Kept 列表。理由：停在别的仓库是临时看一眼，隔天打开发现看板不是当前仓库，容易愣一下。另一种是记住上次停在哪。
3. **没东西可看的几种情形也画仓库按钮**。不做的话，没有焦点窗格时切不过去，建议做。
4. **`Back to <名字>` 的三种例外写 `Follow focus`**（没有焦点窗格、焦点窗格不在仓库里、焦点就在正看的这个仓库）。
5. **每行悬停提示完整路径**。

## 怎么算做完
- 用户原话：“我现在又不想每次都要打开这个repo才能知道我的未立项的想法”——不把焦点挪过去、那个仓库没有开着的窗格，也能在看板上看到它的任务文件。“样稿可以”——样子和三张样稿一致，上面「要做的」逐条达到。
- 先写测试、确认它因为功能还没有而失败，再实现。下面四样各有测试即可，不做覆盖矩阵：
  - 菜单里列什么：开着的仓库去重、按名字排、去掉已在 Kept 里的；两段各自为空时不出现。
  - Kept 列表的加、移、存、读（不存在的目录跳过、重复的不加）。
  - 看板读哪个目录：跟焦点时是焦点窗格的，选了仓库后是选的那个，移掉正在看的之后回到焦点。
  - 右上角按钮写什么：`Back to <名字>` 和三种 `Follow focus`。
- 验证只做这些：在 `app/` 下带上面的 `CARGO_TARGET_DIR` 跑 `cargo test --all-targets`、`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check`，再跑 `git diff --check`，各一次。觉得不够，在回复里说，不要自己加。
- 不起窗口、不截图。样子和手感留给用户实际看：菜单开关、切过去、切回来、移掉、`Choose folder…`、没有焦点窗格时切、右侧栏拖到最窄时顶行、加宽成并排的列时顶行。
