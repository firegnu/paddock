4. **主题取色接口**：新建 `app/src/theme.rs`。下面是后两个任务要共同遵守的约定，名字照写：

   ```rust
   pub struct Theme { /* 私有字段 */ }
   impl Theme {
       /// 由配置构造；本任务里始终用 Dune，配置中的 theme 和 [colors] 先不生效。
       pub fn from_config(config: &crate::config::Config) -> Result<Theme>;
       /// 取 Saddle 主题里的一个界面颜色当文字色用；Reset 解析为终端默认字色。
       pub fn fg(&self, pick: fn(&saddle::theme::Theme) -> ratatui::style::Color) -> palette::Rgb;
       /// 同上，当背景色用；Reset 解析为终端默认底色。
       pub fn bg(&self, pick: fn(&saddle::theme::Theme) -> ratatui::style::Color) -> palette::Rgb;
       /// 终端窗格用的配色（现有的 palette::Theme，主题任务会扩充它）。
       pub fn terminal(&self) -> &palette::Theme;
   }
   ```

   - 界面颜色取自 `saddle::theme::Preset::Dune.theme()`，不复制色值。ratatui 的具名色和索引色（如 `DarkGray`、`Indexed(n)`）按终端调色板解析成具体颜色。
   - 终端配色沿用原型现在的值（`view.rs` 里的前景、背景、光标加 xterm 16 色），不调整。
   - 窗口、标题栏、终端窗格的颜色都改成从 `Theme` 取，不再在 `view.rs` 里写死。
