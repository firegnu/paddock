## 要做的
1. **共用弹出框样式**（`popover.rs`）：一个浮层容器和一种菜单行，照样稿：容器圆角 10、主题里比侧栏略亮的底、一条淡边线、柔和阴影、内边距 5；行高 30、圆角 6、左边 14pt 图标、右边淡色快捷键、悬停变亮；分组之间一条淡横线。下一件 P5-4c 的新标签、分屏、Attention 也要用它，所以做成通用的；本轮只有底部菜单用。
2. **P5-10 底部按钮**：底部五个图标换成左下角一个 32pt 的图标按钮（只放图标，不写字，旁边不写当前排序）。点开菜单，向上弹出，贴着按钮左对齐：New Agent…（⌘⇧N）、New Shell（⌘N）｜Sort（行内 Status / Name 两段选，当前的高亮）、Fold（开着时打勾）｜Stop <选中的 agent 名>…（悬停变红；没有选中 agent 时变灰、点不了）｜Settings…（⌘,）。各项做的事和现在对应按钮或菜单栏一样；点了菜单项后菜单收起；Esc、点菜单外面也收起。悬停按钮有英文说明。
3. **P5-11 分割线**：侧栏和右边之间一条 1pt 的主题淡色线（各主题都看得出又不抢眼）。鼠标移到线上（左右各留几 pt 好抓）时光标变左右拖动、线变亮，按住拖动改侧栏宽度，宽度限制在 220 到 560pt；松手后把宽度写回配置文件的 `sidebar_width`（用 `settings.rs` 现有的 draft，不改动用户文件里其他内容）。标题栏里标签的起点跟着侧栏宽度走。
4. **P5-11 收起**：侧栏头部 `Agents` 一行最右边加收起按钮；⌘B 收起或展开（菜单栏里也有这一项，palette 的命令里能找到——看现有命令从哪来，照着加）。收起后是 52pt 窄条，自上而下：展开按钮、铃铛（有事时带数字，颜色规则和现在头部铃铛一样，点开 Attention）、一条短线、每个 agent 一个约 34pt 的圆角方块（名字首字母，去掉 `dev-`、`test-` 这类前缀后取；右下角状态点，工作中呼吸；选中的有底色和淡框），不同项目之间一条短线；最底下是第 2 条的图标按钮，菜单照样向上弹。点方块等于点卡片（选中并打开）；悬停方块显示说明：名字、种类、状态（含多久）、项目和分支。收起状态随布局文件保存，下次启动保持；旧布局文件读进来默认展开。收起和展开时宽度变化可以有一个很短的过渡，不做也行。
5. 界面文字一律英文；只从主题取色，可以加透明度，不新增主题颜色键；字号用 `ui.px`，三套预置主题、界面字号 13 和 18 下都要好看、不折行。
