## 要做的
用户原话：“我想有一个地方能够设置ui的字体以及大小等”；“ui和终端我要分开设置”；“两种都要有从现有字体中选，现在就是自己填写，太简陋”。用户选定的做法：

1. **界面字体**：设置窗口 General 页新增界面字体和界面字号两项，和终端字体分开。管终端以外的全部界面文字：侧栏、标签栏、Attention、Go to Agent、终端查找栏，以及设置、About、New Agent 窗口。改了即时生效。没设时和现在的样子一样（现在的系统界面字体和各处现有字号）；字号是基准，各处现有的大小关系保持（如标题比正文大、说明比正文小）。
2. **字体选择器**：界面字体和终端字体都改成可搜索的下拉，取代现在手填的文字框。点开是列表，顶上能打字筛选，每个字体名用它自己的字体显示；↑↓ 选、Enter 确定、Esc 关。字体来自本机已装字体（GPUI 有 `cx.text_system().all_font_names()`）。界面字体列全部，终端字体只列等宽字体（按字宽自动判断）。用户选定的样子：

   ```
   Settings → General

     Interface font    [ System (SF Pro)       ▾ ]
     Interface size    [ 13 ] pt

     Terminal font     [ Menlo                 ▾ ]
     Terminal size     [ 14 ] pt
     Line height       [ 1.2 ]

   点开 Terminal font：
     ┌────────────────────────────────┐
     │ ⌕ mono_                         │
     ├────────────────────────────────┤
     │ ✓ Menlo                         │ ← 每行用该字体本身显示
     │   JetBrains Mono                │
     │   SF Mono                       │
     │   Monaco                        │
     │   …                             │
     └────────────────────────────────┘
   ```
3. **终端字体即时生效**：终端字体、字号、行高保存后，正在显示的终端立刻按新字体重排；里面运行的 shell 和 agent 收到新的窗口尺寸（和拖动窗口大小时一样）。不再标“需要重启”。
4. 配置文件：终端字体沿用现有的键（`font`、`font_size`、`line_height`、`font_fallbacks`），旧配置照常能读；界面字体新加的键名你定，写进 `app/README.md` 的配置说明。保存时沿用现有做法（保留配置文件里的注释）。
