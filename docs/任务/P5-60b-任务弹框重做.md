   - ID：预填下一个空编号；撞号、格式不对时照现在的规矩不让建，就地说明。编辑时锁定。
   - Title：必填。
   - Priority：High／Medium／Low 三段，默认 Medium；写法照 P5-60a（中＝不写这一行）。
   - Waits for：下拉，默认 None，列出这个仓库 `docs/任务/` 里现有的任务（main 上和草稿），可以输入筛选；选了就写 `依赖：<编号>`。
3. **正文**：已有的多行输入框（`TextInput::wrapping(true)`），等宽字体；上面 Write／Preview 两个标签。新建时预放：
   ```

   ## 怎么算做完
   ```

5. **新建写出的文件**：

   ```
   <YYYY-MM-DD>，用户在看板上新建。
   依赖：<编号>          ← 选了才有
   优先：高              ← 不是中才有

   ```
