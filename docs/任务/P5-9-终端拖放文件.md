## 要做的
1. 从访达把一个或多个文件（图片或任何文件）拖到某个终端窗格上松手：把它们的路径写进这个窗格，和 Ghostty、Terminal 的做法一样——每个路径按 shell 规则加引号（含空格、引号、`$`、反斜杠、换行等特殊字符时也安全），多个之间用一个空格隔开，末尾加一个空格，不回车。
2. 写入沿用现有粘贴的路径：终端开了括号粘贴模式时用括号粘贴（Claude Code 等就能把图片路径认成附件），没开时照现有粘贴的规则处理。
3. 拖到哪个窗格就写进哪个窗格，并把焦点给它；拖着经过窗格时有一个安静的提示（例如窗格上一层淡色高亮），离开或松手后消失。拖到侧栏、标题栏上不处理。
4. 拖进来的不是文件（例如一段文字），不处理也不出错。
