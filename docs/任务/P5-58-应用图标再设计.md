## 要做的
1. **图标画法**：照定稿候选，1024 坐标系。
   - macOS 图标网格的圆角方块（824/1024，圆角 185），Candy 深靛蓝竖向渐变底（#1d2152 → #0a0b24），顶部淡高光、淡亮边。
   - 马头侧面朝右：脸是奶黄 → 粉 → 紫的渐变（#fff3a6 → #ff9ad5 → #9b7cff）；后耳和鬃毛是粉 → 紫 → 蓝（#ff9ad5 → #9b7cff → #4f6bff）；鬃毛圆头（轮廓外扩 20 圆角），带一绺垂到额头的额毛。
   - 光影：整体落在底板上的柔和投影；左下暗、额头一块柔高光、头部右上一圈亮边；鬃毛在脸上投一道阴影。
   - 五官：大黑眼睛带两个亮点，脸颊粉色腮红，鼻孔。
   - **32 及以下用简化版**：去掉腮红、额头高光、亮边和鬃毛投在脸上的阴影，眼睛放大、只留一个亮点（照 P5-20 “32 及以下去掉色散和光晕”的做法）。
2. **实现**：图标改为仓库里的两份 SVG（完整版、简化版，`app/src/icon/` 下），`icon::icon(size)` 用 resvg 画成 RGBA，对外接口不变，`bundle.rs`（`AppIcon.icns`）和 About（P5-46）都自动跟着变。
   - resvg、usvg 是 GPUI 已经锁定的 0.46，直接依赖只在锁文件多一行引用、不加新包（和 P5-46 直接依赖 `image` 一样）；不开默认特性（不要文字、系统字体、位图）。
   - 删掉 `icon.rs` 里画猫头的代码；测试改成检查新图标（透明边、圆角方块里的底色、马头在、各尺寸都画得出、32 及以下用简化版）。
3. **文档**：DESIGN §13 加 P5-58 条（写用户原话，注明取代 P5-20 的猫头）；样稿源文件放 `docs/设计稿/P5-58-应用图标/`（画布三块的 `.dc.html` 加 README），照 P5-20 的做法。
