## 要做的（照样稿，用户选的都是 A）
1. **标签切换（1A）**：切到别的标签时，新标签的内容 120 ms 淡入，同时顺着切换方向平移 4 px 到位（往右边的标签切，内容从右边 4 px 处移过来；往左反过来），曲线同浮层 `POP_CURVE`。旧标签的内容直接消失，不做淡出；标签条和侧栏不动。
2. **侧栏卡片换位（4A）**：卡片位置变了（agent 出现、离开、状态变化引起重新排序、改排序方式）时，留下的卡片 160 ms 从旧位置滑到新位置，曲线 `POP_CURVE`；新出现的卡片在它的位置上淡入（约 140 ms）；离开的卡片淡出（约 140 ms），它空出来的地方随下面的卡片滑上来收拢。展开、收起卡片引起的高度变化不在本件（照旧直接变）。
3. **状态涟漪（5A）**：一个 agent 变成 Idle（停下、做完）或变成需要你（`Status::Waiting`）的那一刻，它卡片角标的状态点放出一圈淡环：从点的大小扩到约 3 倍，同时从约 55% 不透明淡到 0，600 ms，曲线 `POP_CURVE`，颜色用新状态的颜色，只放一次。需要你的琥珀点之后照旧一直轻跳；干活的转圈不变。侧栏刚打开、paddock 刚启动时第一次读到的状态不放（只在“变了”的时候放）。
4. **系统开了“减弱动态效果”**：三样都直接到位，不平移、不滑、不放涟漪（标签内容和卡片的淡入淡出可以去掉，也可以只淡不动，由你定，写进完成记录）。
5. **不动的时候不要帧**：过渡结束后不留定时器、不再要帧（P5-143a 的省电不能丢）。
