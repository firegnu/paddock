3. **状态涟漪（5A）**：一个 agent 变成 Idle（停下、做完）或变成需要你（`Status::Waiting`）的那一刻，它卡片角标的状态点放出一圈淡环：从点的大小扩到约 3 倍，同时从约 55% 不透明淡到 0，600 ms，曲线 `POP_CURVE`，颜色用新状态的颜色，只放一次。需要你的琥珀点之后照旧一直轻跳；干活的转圈不变。侧栏刚打开、paddock 刚启动时第一次读到的状态不放（只在“变了”的时候放）。
4. **系统开了“减弱动态效果”**：三样都直接到位，不平移、不滑、不放涟漪（标签内容和卡片的淡入淡出可以去掉，也可以只淡不动，由你定，写进完成记录）。

## 完成记录

### 做了什么
- **标签切换（1A）**：`window_motion.rs` 的 `Motion` 每帧记下正在显示的标签（机器 + 标签 id）。换到同一台机器上、原标签还开着的另一个标签时，新内容 120 ms（`POP_IN`）淡入，同时从切换方向那边平移 4 pt（`POP_RISE`）到位，曲线 `POP_CURVE`。方向按两个标签在标签条上的位置定（往右切，内容从右边来）。`window.rs` 只在动的时候给标签内容包一层 `relative().left(shift).opacity(..)`：只挪位置，不改大小，终端不重排；标签条、侧栏不动，旧内容直接消失。
- **侧栏卡片换位（4A）**：新文件 `sidebar_motion.rs`（`sidebar.rs` 里以 `cards_motion` 模块引入）：
  - `CardMotion`：每帧拿列出的 agent（及其显示状态）和画出的卡片顺序，跟上一帧比：有 agent 出现或离开、改了排序方式、两帧都画了的卡片先后变了，才“上膛”，这一帧排出来的位置变化才滑。
  - 两个包裹元素：`Anchor` 包列表，记下列表排版位置；`Slot` 包每张卡片，prepaint 时拿卡片排版位置（去掉滚动偏移，相对列表）跟上次比，然后用 `window.with_element_offset` 把卡片画在“还要滑多远”的位置。布局不变，也不会先闪一帧新位置。
  - 留下的卡片 160 ms 滑到新位置，中途又换位置时从当前画到的位置接着滑。新 agent 的卡片在它的位置上 140 ms 淡入。离开的 agent 的卡片留一份在列表里绝对定位，在原处 140 ms 淡出，下面的卡片同时滑上来；这份淡出的卡片画在别的卡片下面，点了没反应。
- **状态涟漪（5A）**：agent 的显示状态（`Panel::shown`）从别的状态变成 Idle 或 Waiting 时，卡片角标的点用一层 `BoxShadow` 放一圈淡环：600 ms，直径从点的大小扩到 3 倍，不透明度从 55% 到 0，`POP_CURVE`，颜色用新状态的颜色，只放一次；中途状态又变就停。Waiting 的轻跳照旧，淡环和它叠着画；转圈不变。窄条的角标传 `None`，不放。
- **第一次读到不放**：corral 还没读到、侧栏只画窄条、这台机器不在前台（`set_on_show(false)`）时清掉状态。所以侧栏打开、paddock 启动、换回这台机器时，第一次读到的东西都直接到位：不滑、不淡入、不放涟漪。
- **减弱动态效果**：标签内容只淡入不平移；卡片不滑（直接到位）、只淡入淡出；不放涟漪。
- **不要帧**：标签过渡并入 `Motion::moving`。卡片的淡入淡出和涟漪在侧栏 render 里按 `fading()` 要帧，滑动由 `Slot` 在 prepaint 里要帧；都到位后不再要帧，也没留定时器。
- `docs/DESIGN.md` §13 在 P5-148a 后面加了 P5-154 一条，写明上面的行为和边界。

### 拿主意的地方
- 标签切换不只在 `select_tab` 里触发，而是看每帧显示的是哪个标签，所以点标签、⌘1…⌘9、⌘⇧[ / ⌘⇧]、命令面板、新开标签、在别的标签里显示 agent 都会走这个过渡。方向按位置定：⌘⇧] 从最后一个绕回第一个时，内容从左边来。原标签被关掉、换机器时直接到位。

- 淡入、淡出只算 agent 出现、离开（按 corral 列表），折叠或展开分组让卡片出现消失时不淡。
- 减弱动态效果：卡片和标签选了“只淡不动”，跟 P5-148a 浮层的做法一致。
- 涟漪用 `BoxShadow` 往外扩：跟 Waiting 轻跳的画法一样，不改布局，也不会被角标裁掉。

### 踩过的坑
- 卡片滑动测试的第一版把“还在动”和涟漪混在一起：卡片变成 Waiting 时同时放 600 ms 涟漪，“160 ms 后不再动”就断言失败。测试里把“在滑”和“在淡、在放涟漪”分开检查，实现没改。
