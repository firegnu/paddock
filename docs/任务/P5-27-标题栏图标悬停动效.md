## 完成记录

- **做了什么**：沿用 P5-26 的 `motion::hover_motion`，`motion.rs` 新增四组时长（`SHIFT` 360ms、`SPIN` 320ms、`PART` 380ms、`TILT` 420ms）和对应的姿态计算 `shift`、`spin`、`part`、`tilt`，缓动照任务（侧栏开关和分屏 `cubic-bezier(.45,0,.2,1)`，`+` 用回弹曲线，搜索用 `.36,.07,.19,.97`）。`footer_icon.rs` 的 `Pose` 加了 `Shift`（侧栏开关的竖线和三道短横一起横移）、`Turn`（`+` 绕中心转、放大镜绕镜片中心转，只有手柄动，镜片转了还是原样）、`Part`（分屏拆成左右两个各自封口的半框，`+` 跟右半走）；加了一个小函数 `turned`。`window.rs` 里标题栏的新标签 `+`、分屏、Search、右侧栏开关改成 `hover_motion` 包着原来的按钮，样式和点击不变；`sidebar.rs` 的 `collapse_button` 同样改了，收起后窄条上的展开按钮用的是同一个按钮，所以也有。窗格标题上的分屏、palette 里的放大镜仍用不带姿态的 `footer_icon::icon`，不动。
- **验证了什么**：`motion::tests` 新增 5 项：侧栏开关 180ms 时向右 +1.5、向左 −1.5，360ms 回到 0；`+` 中途超过 90°，320ms 正好 90°；分屏 190ms 时每半 0.9，380ms 合上；放大镜 126ms 时 −14°、273ms 时 8°、420ms 回 0；四个动效在减弱动态效果下都不播放（`play` 为空、`Next::Idle`、姿态都是 `Rest`）。在 `app/` 下 `cargo test --all-targets` 全过（共 244 项，库 207 项），`cargo clippy --all-targets -- -D warnings` 无警告，`cargo fmt --check` 通过，`git diff --check` 干净。用 release 程序、`PADDOCK_NO_ACTIVATE=1`、临时 HOME/XDG、假 corral（两个虚构 agent）起了自己的窗口，只截这个窗口：标题栏静止时左侧栏开关、`+`、分屏、Search、右侧栏开关和原来一样（截图在会话 scratchpad，未入库）；按 PID 停掉。动画本身截不到、也不能模拟悬停，留给用户在真窗口里看。
- **拿主意的地方**：① 任务只给了放大镜“0 → −14° → 8° → 0”，没给每一步的时刻，我定在 30% 和 65%（先快歪、后慢回，和铃铛前紧后松的节奏一致）。② 方向在每一帧按当前状态算：鼠标进来后 360ms 内就点了开关，侧栏状态一变，剩下的半程会反向（最多跳约 3pt，一闪而过）；没为此改动画机制。③ 分屏静止和播放首尾（位移为 0）时画原来的整框加中缝，只在拆开时画两个半框，保证静止样子不变（两个半框叠在中缝会把中缝描两遍，边缘略重）。④ 侧栏开关向外滑 1.5pt 时，左开关的短横会压到外框左边线上一点，照参数没改。
