## 要做的
只对 `marks.tone == TabTone::Working` 的标签（选中的、没选中的都算）：
1. 胶囊的边换成跑马灯：整圈是很淡的干活蓝，一段尾巴从淡到亮沿着胶囊的边（两头半圆、中间直线，整圈都要贴着边走）一圈圈跑，最亮的头接近白；一圈约 2.5 秒，匀速。边的粗细和现在差不多（可以比 `TAB_RING` 略粗一点让它看得清，开发定，不改胶囊的高和宽）。
2. 所有干活的标签同一个节拍（同一时刻亮点在各自胶囊的同一相对位置），用 `repeat_synced` 这类同步的写法。
3. 没选中的干活标签整条跑马灯调暗到大约六成；底色、文字照现在。
4. 跑马灯在跑的标签，图标角上的状态点不再呼吸（静止的蓝点，和样稿一致），免得两处同时动。侧栏卡片等别处的点照旧呼吸。
5. 系统“减弱动态效果”开着时：不跑，标签画成现在的样子（现在的边色、点照现在）。
6. 不变的：等人（含没选中的标签因为别的窗格要人而出的黄圈：有黄圈就照现在画黄圈，不跑马灯）、出错、有新回复、暂停、shell 标签；悬停、选中的底色、`×`、宽度、分屏标签的叠卡。
7. 动画帧率照 `corner_dot` 的限法，不要因为这个让整个窗口满帧重画。
