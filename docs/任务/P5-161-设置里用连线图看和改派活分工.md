## 样子
- 样稿：https://claude.ai/artifact/Pw9Cs5uQyApLgk6PNJpXL9（甲、乙两种画法，加一张出错提示）。
- 用户 10-20 选甲（“接受你的推荐。”）：
  - 左边一列格子，按数据给的顺序，每格写名字、ranch 给的说明，右端一个小标写模型和强度（没有就写 `default`），本机改过的标 `Changed`。
  - 中间一列是家，格子到家一条实线（一格多家就多条），线用家的颜色；选中的格子线加粗，别的变淡。
  - 交叉审查是从格子绕到审查格子的虚线带箭头，返工换格子是另一种点线。
  - 右边是选中格子的编辑区：交给哪几家（可多选）、模型（下拉加可手填）、强度（下拉，选项随家变）、交叉审查、返工换到哪格；下面只读显示这格的启动命令；按钮 Reset to default（内置未改过时不可点）、Save。
  - 出错提示照样稿第三张：ranch 拒了显示它给的原因；文件被别处改过提示 Reload、不覆盖；ranch 还不能改表时整页只读；读不了表显示报错。

## 现在是怎样（主控 10-20 对着本机命令和代码核对的）
- 现装 ranch（`versions/7d2ac96`）有 `ranch dispatch cell <格子>`、`ranch dispatch table`，只读；本机 `~/.ranch/dispatch.toml` 还不存在，12 格全是内置的。
- Settings 的页在 `app/src/settings.rs` 的 `Page`（General、Appearance、Agents、Machines、Instructions、Sandbox、Diagnostics）；Sandbox 页（`settings_sandbox.rs`，P5-120、P5-160）是同类的先例：只调一个外部命令、读它的 JSON 画出来。

## 要做的（ranch 需求原文的意思）
1. Settings 加一页，用连线图画这张表：每个格子（带说明）连到交给的家，看得出模型和强度；交叉审查、返工换格子用另一种线。看得出每格是内置的还是本机改过的。
2. 在面板上改一格：交给哪几家、模型、强度、交叉审查格子、返工格子；强度、模型给下拉，选项来自 ranch；能把一格恢复默认。改完就写进去，面板随之更新。
3. ranch 拒绝的改动（不合格、文件在别处被改过）显示原因；文件被别处改过时提示刷新，不覆盖。
4. 各家的启动命令只显示，不能改。

## 规矩
- 只调 PATH 上的 `ranch dispatch` 命令、读 JSON；不读写 `~/.ranch` 里的文件。
- 格子有哪些、叫什么、什么顺序都由数据决定，界面不写死。ranch 以后（R34）会把格子整个换成「档位 × 界面或非界面」，面板要照样能用。
- 什么活落进哪一格是 corral-dispatch 技能里的规则，面板不管，也不改技能。
- 界面文字用英文；格子说明是 ranch 给的数据，照原样显示。
