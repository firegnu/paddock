## 要做的
用户原话：“左侧agents面板是不是涉及到4个图标？一个铃铛，agent中的一个复制一个停止还有左下角的settings。我想的是这几个图标加一个特效。哈哈。鼠标移动上的时候搞一个动画之类的。”试过演示后：“批准，你设计的很好。”

1. **照演示做四个动画**，参数照 `README.md`（时长、关键帧、缓动、中心）；图标是代码画的路径，按动画进度改几何（旋转、平移、缩放、圆角、颜色），不要换成图片：
   - 铃铛：以顶部为轴摆两下、幅度递减，铃舌晚一拍。头部的铃铛、紧凑的铃铛、窄条上的铃铛都要有。
   - 复制：悬停时前框推一下再弹回；**点击后变成绿色 ✓**（从小弹到原大），约 1.2 秒后恢复成复制图标。
   - 停止：悬停时缩小一点、圆角变大、变红、底色淡红；离开时反向回去（这个是跟着悬停状态的过渡，不是播一次）。
   - 设置：三个圆钮依次滑开再滑回，圆钮盖住滑杆。
2. **只在鼠标进入时播放一次**，不循环；还在播放时离开再进入，从头播即可。不悬停时没有任何重画。
3. **减弱动态效果**：macOS 辅助功能里打开“减弱动态效果”时，不做任何移动和缩放，只保留颜色、底色的变化和复制的 ✓（直接出现，不弹）。启动时读一次即可；做到能跟着系统设置变化更好，但不强求。
4. 做成能复用的小机制（例如“悬停播放一次”的辅助函数），以后标题栏的图标也会用到；但本轮只接这四个。
5. 只从主题取色、可加透明度，不新增主题颜色键；尺寸跟着 `ui.scale`。

## 完成记录

- **做了什么**：新增 `app/src/motion.rs`，是一个能复用的“悬停动效”小机制：`hover_motion(key, timing, build)` 每帧用当前的 `Hover`（是否悬停、进入后播放了多久、跟着悬停的过渡进度、点击后多久、是否减弱动态效果）把按钮造出来；状态放在 GPUI 的 `use_keyed_state` 里，只在有东西在动时 `request_animation_frame`，✓ 停留的 1.2 秒只等一个定时器，静止和不悬停时不重画。另有三次贝塞尔缓动和逐段关键帧插值（与 CSS 一样，缓动作用在每两个关键帧之间），以及四个图标的姿态计算（`ring`、`copy`、`press`、`slide`）。`footer_icon.rs` 加了 `Pose`，按姿态改路径几何（铃铛绕 (7, 1.8) 旋转、铃舌单独转；复制前框平移；停止方块绕中心缩放并改圆角；三个圆钮平移），并加了演示里的 ✓（`Icon::Copied`，线宽 1.4）。新增 `reduce_motion.rs` 读 `NSWorkspace.accessibilityDisplayShouldReduceMotion`（`objc2-app-kit` 加 `NSAccessibility`、`NSWorkspace` 两个特性，`Cargo.lock` 没变）。`sidebar.rs` 里头部铃铛、紧凑铃铛、窄条铃铛、卡片的复制和停止、左下角菜单按钮接上了动效；卡片按钮原来用两个叠放的图标切换颜色，改成直接按状态取色。
- **验证了什么**：`motion::tests` 新增 8 项：贝塞尔曲线两端和线性曲线；铃铛在 15%/35%/55%/75% 时是 16°/−12°/7°/−3°，铃舌晚 40ms，560ms 后归位；复制前框在 45% 处推到 1.6，点击后 ✓ 从 0.4 倍、透明开始，260ms 时到原大、不透明；停止方块悬停到头是 0.84 倍、圆角 3.4；三个圆钮分别在 310/370/430ms 到 +4.5/−5/+4；进入时播放一次、离开后不再重画、再进入从头播；减弱动态效果时没有播放、不移动、方块不缩放，✓ 直接整个出现、只等结束那一刻；停止的过渡跟着悬停进出，中途折返从当前位置开始。在 `app/` 下 `cargo test --all-targets` 全部通过（库 202 项，其余目标也都通过），`cargo clippy --all-targets -- -D warnings` 没有警告，`cargo fmt --check` 通过，`git diff --check` 干净。用 release 程序、`PADDOCK_NO_ACTIVATE=1`、临时 HOME/XDG 和假 corral（3 个虚构 agent）起了自己的窗口，只截了这个窗口：能启动，头部铃铛、卡片、左下角菜单图标静止时和原来一样（截图在会话 scratchpad，未入库）。进程按 PID 停掉了。动画本身、悬停、点击复制都截不到，也不能模拟，留给用户在真窗口里看。卡片的复制和停止要点开卡片才出现，这次截图里没有。
- **拿主意的地方**：① 离开时动画继续播完再停，不像演示那样一离开就跳回原位（演示用 CSS `:hover`，离开即中断）；再进入仍从头播。② 减弱动态效果时停止方块的圆角也不变，照任务原话“只保留颜色、底色的变化”（演示的 CSS 在这种情况下仍改圆角）。③ 设置图标的“圆钮盖住滑杆”用滑杆在圆钮处断开、断口跟着圆钮走来实现，而不是用背景色填圆钮：侧栏下面是磨砂材质，填色会露出色块；静止时样子和原来一样。④ 停止的淡红底色沿用现有的 0.12 透明度（演示是 0.14），并随过渡淡入淡出；其余按钮原有的悬停底色不变。⑤ 减弱动态效果在每次鼠标进出时读系统设置，所以改了系统设置后下一次悬停就生效，不用重启。没有打开 GPUI 自己的 `App::reduce_motion`，因为它也会停掉卡片上的转圈和脉动，超出本轮范围。
