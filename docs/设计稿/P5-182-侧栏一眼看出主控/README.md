# P5-182 侧栏一眼看出主控样稿

用户 10-24：“左侧的sidebar中的agent是主控agent的时候，是不是可以一眼看出来，现在委派的agent一多，主控不好找。”主控提了皇冠记号、主控排组顶、整行底色三种，建议前两种合用；用户：“按你的建议，出样稿吧”；看过样稿：“样稿可以，写成正式任务吧”。

原稿在 claude.ai 私有画布「侧栏一眼看出主控样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色取 Lagoon 深、浅两版的近似值，实现时一律从主题取色；侧栏宽 368、头像 34 是示意，实现照现有常量。agent 名字、路径是示意。

| 画板 | 内容 |
| --- | --- |
| `Main.dc.html` 甲 · 深色侧栏 | 左“Now”：按状态排，干活的 `dev-*` 在空闲的 `main` 前面，主控和派出的一样。右“Proposed”：主控头像左上角一顶小皇冠（New Agent 里 Controller 那顶，强调色、垫一圈卡片底色），状态点仍在右下；每组主控排第一 |
| `Rail.dc.html` 乙 · 窄侧栏方块 | 现在（深）、改后（深）、改后（浅）：方块左上角同样的皇冠，每组主控排第一 |
| `Light.dc.html` 丙 · 浅色 + 展开 | 浅色主题的改后侧栏；展开的主控卡片皇冠照旧在头像上，详情不加格子 |
