# P5-113 看板卡片收紧样稿

用户 10-15 发来看板截图：“现在的卡片给人感觉太空了。重新设计一下”。主控看到的原因：编号、标题、记号（Draft／High／Low）各占一行，只有一个 Draft 的卡片也是三行高；DONE 里普通的是一行，Dropped 和 Needs you 的又是大卡片，高低不齐；另外 P5-90 的 Needs you 第二行右边被截断、没有 `…`。

`cards.html` 一个文件里并排三屏，直接用浏览器打开。配色取 lagoon 主题的近似值，实现时一律从主题取色；任务内容照截图，In progress 那张是示意（截图里没有进行中的活）。

| 屏 | 内容 |
| --- | --- |
| 现在 | 照截图画的对照 |
| 甲 卡片收紧 | 仍是一张张卡片；编号在标题左边一栏，记号和时间在右边，通常一两行；Needs you 收成一行；DONE 一律一行，Dropped 写在右边，Needs you 那件下面加一行琥珀色 |
| 乙 一栏一个框 | 每栏的活放在一个框里，条间细线；草稿在编号前画虚线小圈、标题淡一些，不写 Draft；High／Low 只用左边那道线；DONE 不加框 |
