# P5-59 窗格面板样稿

用户 10-09 给了 superlogical 的截图（不入库）：“p5-59这个我其实想要的是图中这个terminal中几个区域的这种分割。”主控对照现状（窗格挤在一张卡片里、3pt 细缝、底色和窗格接近、描边 5%、只有分屏时才有标题行）出样稿，用户：“选A，单窗格也要标题行”。原稿在 claude.ai 私有画布「P5-59 窗格面板」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。配色取自 Lagoon，实现时一律从主题取色；内容是示意。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | 现状：一张大卡片里细缝分开，标题行只在分屏时有 |
| `A-Panels.dc.html` | A：窗口底色压暗，每个窗格一块 12pt 圆角面板，缝和窗口边距统一 8pt，描边 9%（当前 20%）；每块标题行：agent＝种类图标带状态点、粗体名字、淡色会话题目、目录，shell＝在跑的程序名、目录；右边四个按钮（左右分屏、上下分屏、放大、关闭），当前窗格亮、其余淡（**采用**） |
| `B-Panels.dc.html` | B：12pt 缝、14pt 圆角、面板抬亮加阴影、标题行下分隔线（未采用） |
| `Single.dc.html` | 单个窗格有标题行（左，**采用**）和没有（右） |
