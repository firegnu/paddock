# P5-38 标签名不被截短样稿

用户 10-07 问“窗口窄、左侧栏展开时标签名被截得很短（“pa…”）要不要处理”，答：“你要给我你的设计”。主控出三种改法（加一张现在的对照），推荐 A 加 B 兜底，用户：“按你的推荐 A 加 B 兜底，派出去做吧”。原稿在 claude.ai 私有画布「标签名不被截短」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。字宽按 12.5 号字估算，标签和宽度都是示意。

| 文件 | 内容 |
| --- | --- |
| `Now.dc.html` | 现在：其他标签缩到 56 像素，从尾巴截成“pa…” |
| `A-Smart.dc.html` | A 聪明截短：挤时只留能分辨的那段（`paddock`、`newagent`），再挤从中间省略（`new…ent`），每个至少约 78 像素（**采用**） |
| `B-Overflow.dc.html` | B 放不下收进末尾“+N”菜单（**采用为兜底**：A 的最窄宽度也放不下时才用） |
| `C-Chips.dc.html` | C 收成两个字母的小方块（未采用：两个字母常撞车，要靠悬停） |
