# P5-171 标题栏胶囊样稿

用户 10-23 看了 P5-171 第一轮（磨砂时搜索框改深色）装上的样子，发来标题栏截图：“这三个不能作为一个整体做成一个胶囊嵌进去吗？先出设计图吧。”主控出了三种，用户选甲：“甲 交给omp去做”。

原稿在 claude.ai 私有画布「标题栏胶囊样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。放大 2 倍；后面的杂色桌面和磨砂用浏览器模拟，和 macOS 的系统材质不一样，只看结构和方向；颜色取深色主题的近似值。

| 方案 | 内容 |
| --- | --- |
| 现在 | P5-171 第一轮：分屏按钮、深色搜索框、侧栏按钮各自分开 |
| 甲 · 分段胶囊（用户选定） | 一整块深色胶囊，两条淡竖线隔成三段；按钮亮着时整段铺淡白，贴着胶囊圆角，旁边的竖线让开 |
| 乙 · 按钮嵌成小方块 | 同一块胶囊没有竖线，按钮是里面的小圆角方块 |
| 丙 · 外胶囊里再套搜索框 | 搜索在胶囊里还有一层稍亮的小框，字和键帽缩一号 |
