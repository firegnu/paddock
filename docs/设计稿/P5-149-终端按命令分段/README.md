# P5-149 终端按命令分段样稿

用户 10-24 选了主控的三条建议（paddock 自己注入标记；四样一起做；普通 Shell 和 Agent shell 都有、agent 窗格没有），主控画了三块画板；用户：“样稿可以，写成正式任务吧”。

原稿在 claude.ai 私有画布「终端按命令分段样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色取 Catppuccin Latte，实现时一律从主题取色。

| 画板 | 内容 |
| --- | --- |
| `Main.dc.html` 甲 · 往回翻时 | 失败的命令左边一道 2px 细红线，成功的不加；位置条上每条命令一道刻度，失败的是红的；鼠标停在一段旁边，整段淡淡托起、左边出现灰条，提示 `Click the bar to select output` |
| `Jump.dc.html` 乙 · ⌘↑ ⌘↓ | 跳到的命令贴着窗格顶，提示符行亮一下约半秒淡掉；位置条上它的刻度变长；到头不动 |
| `Select.dc.html` 丙 · 选中输出 | 点左边灰条只选输出、不带命令行；用现有选区样子，⌘C 照常 |
