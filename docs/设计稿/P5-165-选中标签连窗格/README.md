# P5-165 选中标签连窗格样稿

用户 10-22 发来一张别的应用的截图（选中的标签和下面的内容卡片连成一块），问 paddock 能不能做成那样；主控评估后画了三张，用户：“甲，右移，边沿新轮廓画，写任务书吧”。

原稿在 claude.ai 私有画布「选中标签连窗格样稿」，这里是同一份源文件（引用的 `support.js` 不在这里，用浏览器直接开看不到动效）。颜色取深色主题的近似值，实现时一律从主题取色；磨砂的透出效果网页里画不出，只看形状和层次。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | 单窗格：现在（胶囊） / 改后（连成一块，整排标签右移） |
| `Split.dc.html` | 分屏：**甲 · 只连正下方那块（采用）**；乙 · 外卡包住整组（未采用）；丙 · 分屏时不连（未采用） |
| `States.dc.html` | 干活中（跑马灯沿新轮廓，**采用**）、等人（琥珀边沿新轮廓，**采用**）、第一个标签贴齐面板左边（未采用，用户选右移）、右侧栏开着、全屏 |

形状（样稿里的数，实现按界面缩放）：标签顶两角圆角 10，两侧底部往外弯的小圆角 8，标签从现在胶囊的顶边往下长到面板顶边；亮边和面板同一种，交界那段面板的亮边让开。
