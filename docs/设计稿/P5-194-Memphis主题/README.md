# P5-194 Memphis 深浅两套主题样稿

用户 10-27 发了一张孟菲斯风格配色（黄 `#FFC93C`、粉 `#FF8DB5`、钴蓝 `#2E5BE6`、珊瑚红 `#FF5A5F`、薄荷绿 `#A9E6C6`、天蓝 `#8DD3F6`、淡紫 `#D3BEFF`，深靛描边 `#25214A`）：“能否增加一个额外的浅色主题。具体的color你可以从这个里面取。”看了样稿后又要：“另外能不能在设计一套对应的dark 孟菲斯。这样颜色就对齐了。”最后选定：“乙，深色照丙”。

原稿在 claude.ai 私有画布「Memphis 浅色主题样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。样稿里的甲（左侧栏暖白）没选。颜色是样稿取值，实现时以对比度测试为准微调。

思路：七个亮色在暖白底上只有钴蓝能直接当字（5.3:1），其余 1.3～2.9:1；深靛底上反过来，只有钴蓝太暗（2.7:1）。所以浅色版把亮色用在大块的底上，字和状态用同色相深一档；深色版亮色原样当字，钴蓝提亮。只换颜色，孟菲斯的描边、硬投影、圆点花纹不做。
