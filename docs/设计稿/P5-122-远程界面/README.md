# P5-122 远程视图的界面优化样稿

用户 10-16 定 P5-122 只做远程显示的界面优化（不做在 paddock 里新建远程 agent），界面优化“主控先出一版样稿”；随后：“对，就这么改草稿，出样稿吧”。

原稿在 claude.ai 私有画布「P5-122 远程界面样稿」，这里的 `.dc.html` 是同一份源文件（引用的 `support.js` 不在这里，画布上的 `Main` 即 `0-Now`）；`remote.html` 是同样内容合成一页的版本，浏览器直接打开（纯 HTML，没有脚本）。照代码画的示意，主控没起窗口截图；配色取 Lagoon 的近似值，实现时从主题取色。机器名 `5090`、agent 名字和路径是编的。

| 屏 | 内容 |
| --- | --- |
| 现在 | P5-90 合并后的远程视图：平的切换标签、窗格看不出机器、右侧栏一行灰字、只在本机的操作出红字 |
| 甲 | 机器切换改成凹槽加实心胶囊（同 P5-121a 的 Cairn 切换），带状态点、`●n`、连不上的短原因 |
| 乙 | 远程窗格标题行加机器小签，名字签后跟机器名 |
| 丙 | 读不到时列表顶上一条横幅加 `Try again`，不逐张写红字；连接中显示 `Connecting to 5090…` 和占位卡 |
| 丁 | 右侧栏 Changes／Kanban／Cairn：丁一 居中说明卡加 `Show This Mac`；丁二 另在标签上标 `Mac` |

| 己 | 甲、乙、丁一、戊合起来 |
