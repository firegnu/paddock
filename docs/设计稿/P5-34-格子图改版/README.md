# P5-34 活动格子图改版样稿

用户 10-07 给了 GitHub 贡献图的截图：“提交格子的样式能否再改一下，酷炫不足。感觉很平淡……或者你可以做的比他更好。”主控出三张样稿，推荐 C，用户：“按你的推荐 C 来，派出去做吧”。原稿在 claude.ai 私有画布「活动格子图改版」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。数据是编的示意（越近越密）；配色取自 Dune／Lagoon／Tide 三套预置，样稿里“发白”是往白色混，实现时改为往主题正文色混。

| 文件 | 内容 |
| --- | --- |
| `C-Heat.dc.html` | C 热流：深色 → 强调色 → 白热的实色阶梯，最忙两档发光，每 7 秒一道光沿对角线扫过有提交的格子，今天那格光圈呼吸更明显（**采用**） |
| `B-Neon.dc.html` | B 霓虹：更亮的阶梯，忙的格子发光并缓慢起伏，悬停时那一行和那一列微亮（未采用） |
| `A-Steps.dc.html` | A 清亮阶梯：GitHub 式实色阶梯，空格子清楚，只有今天发光（未采用） |
