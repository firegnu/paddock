# P5-70 Activity 毛玻璃样稿

用户 10-09（给了侧栏截图）：“注意下被那个提交记录的卡片挡住的。我想让这个提交记录的卡片投下去，能模模糊糊的看到被挡住的agent。”主控说明 GPUI 没有模糊身后内容的功能（侧栏磨砂是系统给的，只模糊窗口后面的桌面），出三张：现状、方案 1 渐隐加半透明、方案 3 假模糊（被挡住的部分画几份错开的淡影）。用户问推荐，主控推荐 1（3 每帧多画几遍、且要和滚动逐帧对齐），用户：“好，按方案1做”。原稿在 claude.ai 私有画布「P5-70 Activity 毛玻璃」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。颜色照用户截图（暖色主题）取的近似值。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | 现状：卡片在 Activity 上边缘被切断 |
| `Fade.dc.html` | 方案 1：卡片接近 Activity 时变淡，Activity 半透明，后面隐约有影子（**采用**；实现时用 Activity 自己颜色的渐变上沿代替网页的渐变遮罩，GPUI 没有遮罩） |
| `Ghost.dc.html` | 方案 3：Activity 后面画几份错开的淡影，像糊开（未采用） |
