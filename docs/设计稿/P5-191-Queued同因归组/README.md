# P5-191 Queued 同因归组样稿

用户 10-26 发来 canter 仓库看板截图（Queued 18 件，16 件的 `待用户：` 是同一句话，每件两行）：“如果task queue里的任务太多。显示就会像截图那样。需要从红光内心设计一下这块”（“红光内心”应是“宏观上”的误输入）。看过样稿：“选甲，照你的推荐写任务文件”。

原稿在 claude.ai 私有画布「Queued 任务太多时的样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色是浅色主题的近似值，实现时一律从主题取色；任务名取自 canter 仓库（公开）当时的任务。

| 画板 | 内容 |
| --- | --- |
| `Main.dc.html` | 现在：18 件每件两行，第二行同一句 Needs you 重复 16 遍 |
| `A-folded.dc.html` | **甲（用户选），默认收着**：`待用户：` 一字不差的两件以上合成一条琥珀组头（`Needs you`、理由、件数），下面一行淡字列成员标题；理由各不相同的照旧 |
| `A-open.dc.html` | 甲，点开后：组头下每件一行（圈、编号、标题，有依赖的行尾写编号） |
| `B-oneline.dc.html` | 乙：所有 Queued 一行一件，Needs you 只剩行尾琥珀点，理由在悬停 |
| `C-capped.dc.html` | 丙：只列前 5 件，其余 `Show all 18` |
