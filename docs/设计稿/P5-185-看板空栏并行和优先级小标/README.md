# P5-185 看板空栏并一行、Queued 优先级小标样稿

用户 10-24 看主界面截图：“那就使劲想一下这个主界面。看看还有哪些可以更加精细调整的地方”。主控列了 11 条，其中第 6、7 条先出样稿，用户：“三条都出样稿吧”；看过样稿：“6 乙 7 甲”。

原稿在 claude.ai 私有画布「看板与名字签精修样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色是浅色主题的近似值，实现时一律从主题取色；任务名字、时间是示意，标着「示例」的两条不是真任务。

| --- | --- |
| `Empty.dc.html` 第 6 条 | 现在：In progress、To review、Merged 为 0 时各占一行。甲：为 0 时变淡变矮。**乙（用户选）**：为 0 的并成一行小字 `In progress 0  To review 0  Merged 0`，哪栏有活就回到自己的一行 |
