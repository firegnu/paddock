# P5-26 侧栏图标悬停动效演示

用户 10-06 试过：“批准，你设计的很好。”（见 `docs/DESIGN.md` §13 P5-26）。原稿在 claude.ai 私有画布「P5-26 侧栏图标悬停动效」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。动画全在 `<helmet>` 的 CSS 里：关键帧、时长、缓动曲线、变换中心照抄即可；图标几何取自 `app/src/footer_icon.rs`。界面文字一律英文（演示里的中文说明只是给用户看的）。

- 铃铛 `mo-ring`：以 (7, 1.8) 为轴，0→16°→−12°→7°→−3°→0，520ms，`cubic-bezier(.36,.07,.19,.97)`；铃舌同样的摆、晚 40ms。
- 复制 `mo-nudge`：前框 (−1.6, −1.6) 再回，340ms，`cubic-bezier(.34,1.56,.64,1)`；点击后换成绿色 ✓（`M3 7.4l2.6 2.6L11 4.4`），从 0.4 倍弹到 1 倍 260ms，1.2 秒后恢复。
- 停止：悬停时缩到 0.84 倍、圆角 2.5 → 3.4、填色变红，底色淡红，160ms ease-out；离开时反向回去。
- 设置 `mo-k1/2/3`：三个圆钮分别滑 +4.5、−5、+4 再回，620ms，`cubic-bezier(.45,0,.2,1)`，依次晚 0／60／120ms；圆钮盖住滑杆（用背景色填）。
- 减弱动态效果：不移动，只保留颜色和底色的变化。
