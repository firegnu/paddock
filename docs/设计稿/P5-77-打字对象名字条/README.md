# P5-77 打字对象名字条样稿

用户 10-10 的痛点：“假如我现在激活的是agent1， 但是我突然想在agent2中有一个想法和他讨论，这时候我会下意识的输入到agent1中，而不是先切换到agent2,然后输入。”主控提出在开始打字的那一刻、输入框旁边亮出“这是谁”，出了三种放法；用户看后：“我觉得B比较好。你觉得呢？”主控说明 B 实现时只能跟终端光标走，用户：“确认用B，写任务文件吧”（见 `docs/任务/P5-77-看清正在给哪个agent打字.md`）。原稿在 claude.ai 私有画布「P5-77 打字对象名字条」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。配色取自 Lagoon，实现时一律从主题取色；内容是示意。每张左边是平时，右边是停了一阵后打下第一个字的那一刻。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | A 底边名字条：窗格最下面一条 `To 名字 · 会话题目`，平时很淡，开始打字时整条亮起约一秒；每个窗格少一行高度 |
| `B-Pill.dc.html` | B 输入框角上的名字签：平时一枚很淡的小签只写名字，开始打字时亮起并带出会话题目；不占行（**采用**） |
| `C-Flash.dc.html` | C 只在开始打字时出现：平时什么都不加，开始打字时输入框上方浮出名字牌、窗格的边亮一下，约一秒后消失 |
