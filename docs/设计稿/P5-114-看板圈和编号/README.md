# P5-114 看板的圈和编号样稿

用户 10-15 发来 P5-113 之后的看板截图：“kanban中的任务编号不好看清和识别。而且Queued In progress To review Merged Done我觉得几个状态也不太明显。另外不需要要最左边的竖状条了，每个人物前面不是都有一个圈圈吗。把颜色挪到那个圈圈上。你觉得如何？”

`rings.html` 一个文件里并排三屏，直接用浏览器打开。配色取 lagoon 主题的近似值，实现时一律从主题取色；内容是示意（paddock 和 ranch 的任务混着放，In progress 那条是假的）。

| 屏 | 内容 |
| --- | --- |
| 现在 | 照 P5-113 画的对照 |
| 甲 圈只管优先级 | 去掉竖条；每件活前面一个圈（草稿虚线、提交了的实线）；Queued 里圈的颜色是优先级，别的栏一律浅灰；编号 12 号、亮一档；分组标题字大一号、前面的点换成栏颜色的圈 |
| 乙 圈管状态（主控推荐） | 圈的样子跟着栏变：Queued 空圈（颜色是优先级），In progress 蓝色半圈，To review 黄色大半圈，Merged 绿色打勾，Done 灰色打勾，Dropped 灰圈带斜线、不再写 Dropped 胶囊；分组标题前面用同一个图标；编号同甲 |
