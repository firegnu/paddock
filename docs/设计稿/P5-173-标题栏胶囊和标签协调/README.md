# P5-173 标题栏胶囊和标签协调样稿

用户 10-23 发来标题栏截图，箭头指着右端的胶囊（分屏、Search、右侧栏）：“我还是觉得最右边的那几个工具胶囊和整体的这个上面的条条不协调”。主控出了三种，用户选甲：“甲 交给omp去做”。

原稿在 claude.ai 私有画布「标题栏右端胶囊样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。放大 1.5 倍，画的是磨砂打开时；颜色取深色主题的近似值，壁纸用暖色渐变代替，小宠物用色块代替。

三种都顺带做两件事：胶囊和标签、`+` 落在同一条线上（原来胶囊比标签文字高 2pt）；`⌘P` 不画成两个键帽方块，改成一行淡字。

| 方案 | 内容 |
| --- | --- |
| 现在 | 1pt 描边加 60% 半透明外框色底，两道竖线，两个键帽方块；居中在整条上，没跟标签一起下沉 |
| 甲 · 和选中标签同一块料（用户选定） | 去掉描边，底色用选中标签接面板时那种实心深色，圆角 8、高 28 和标签一样，竖线再淡一半 |
| 乙 · 平铺在条上 | 不要底和描边，三样像没选中的标签一样平铺，鼠标放上去出淡底 |
| 丙 · 挂在右侧栏上 | 右侧栏开着时胶囊往下接进右侧栏，关上时退回甲 |
