# P5-85 看板切换仓库样稿

用户 10-11 谈 P5-83（还没立项的想法放哪、怎么看得见）时说：“我现在又不想每次都要打开这个repo才能知道我的未立项的想法”。主控提了一个和“想法仓库”无关的通用做法：看板可以切到别的仓库看，焦点不用挪过去。用户：“我觉得还挺实用的，但是这个切换你打算怎么做？切换的只限制在左侧agents所在的所有repo还是？”主控答了做法和两处建议（选过的仓库留在菜单里；只切看板，Changes、Cairn 照旧跟焦点），用户：“都按你的建议来，出样稿吧”；看过样稿：“样稿可以，写任务文件吧”（见 `docs/任务/P5-85-看板可以看别的仓库.md`）。

原稿在 claude.ai 私有画布「看板切换仓库样稿」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里；画布上三张叫 `Main`、`Menu`、`Kept`）。配色取 Lagoon 的近似值，实现时一律从主题取色；面板宽 440 是示意。三张都是静态的，没画悬停。第三张里的卡片标题是占位的。

| 文件 | 内容 |
| --- | --- |
| `1-Follow.dc.html` | 平时：跟着焦点，和现在一样，只是仓库名后面多一个小箭头，仓库名是个按钮 |
| `2-Menu.dc.html` | 点仓库名弹出的菜单：`Follow focused pane`（默认，打勾）、`Open now`（现在开着的仓库）、`Kept`（选过的仓库，行尾 × 移掉） |
| `3-Kept.dc.html` | 切到别的仓库之后：标签行不变；仓库名按钮带强调色细边和图钉图标，表示没在跟焦点；原来写概况的位置是 `Back to paddock` 按钮 |

样稿上没画、任务文件里另外写明的：没东西可看的几种情形（没有焦点窗格、不在仓库里等）也要有仓库按钮；菜单最下面的 `Choose folder…`。
