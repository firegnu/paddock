# P5-101 模型选单和 Models 一节精修样稿

用户 10-14 看了 P5-100 装好的样子问“这几个页面不能做的更加好看精致一些吗？”，主控出了这几张。用户选 A（一列）、Settings 用 C、强度改成滑块（D），看过 D：“可以，写任务文件开始做吧”（见 `docs/任务/P5-101-模型选单和Models一节精修.md`）。

原稿在 claude.ai 私有画布「模型选单和 Models 一节精修样稿」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。配色取 Lagoon 的近似值，实现时一律从主题取色。

| 文件 | 内容 |
| --- | --- |
| `A-一列.dc.html` | 选单 A：模型一个一行、选中打勾、默认的写 `default`；强度还是一条分段条（后来改成 D 的滑块） |
| `B-两列.dc.html` | 选单 B：两列、名字前小圆点（没选） |
| `C-Settings.dc.html` | Settings › Agents › Models：模型成可换行的小标签、来源写在名字下、`Refresh` 带图标；问失败、正在问两种状态 |
| `D-滑块.dc.html` | 可操作：A 的选单加强度滑块，换档回弹、颜色随档位变暖、高档外圈脉冲；可切 Claude／Codex |
