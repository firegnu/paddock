# P5-87 收件箱样稿

用户 10-11 谈 P5-84（各仓库主控之上要不要再有一个 agent）时说：“我的注意力主要是来回在各个主控之间切看消息。”主控提议不加 agent，把左侧栏铃铛点开的名单做成收件箱：各主控最后一条回复的原文排在一处，能就地回一句。用户：“同意，出样稿吧，入口在哪还有展现是如何的，你要弄清楚”；看过样稿：“看起来还是不错的”；主控又建议砍掉“显示全部 agent”的开关、加上表格，用户：“都按你的建议来，写任务文件吧”（见 `docs/任务/P5-87-收件箱.md`）。

原稿在 claude.ai 私有画布「收件箱样稿」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里；画布上四张叫 `Now`、`Main`、`Prompt`、`Sent`）。配色取 Lagoon 的近似值，实现时一律从主题取色。四张都是静态的，没画悬停。里面的回复文字是编的。

| 文件 | 内容 |
| --- | --- |
| `0-Now.dc.html` | 现在：铃铛点开只有名单，点一行就跳到那个窗格 |
| `1-Inbox.dc.html` | 整个窗口：铃铛点开是收件箱。左边名单（Needs you、New replies、Read 三组，每行一句预览），右边是选中那个 agent 最后一条回复的原文，底下是回复框 |
| `2-Prompt.dc.html` | 只画弹层：选中的 agent 在自己窗格里弹着提问。这里回不了，给一个 Open pane 跳过去 |
| `3-Sent.dc.html` | 只画弹层：回完之后。留着发出去的那句，状态变成 Working，这一轮结束前不能再发 |

样稿上的出入，以任务文件为准：
- 名单的行画成了圆点加名字；实现时名字、项目、图标、时间照现在名单的画法，只多一行预览。
- 样稿没画表格。回复里的表格要排成表格，见任务文件。
- 画布上还有一张备选（放在右侧栏做第五个标签），用户选了铃铛弹层，没抄进来。
