# P5-167 标签居中放大样稿

用户 10-23 想再调一下标题栏上选中标签的样子：“再大一点，然后左边的图片和文件作为整体居中显示在激活的tab上”。主控问了两点（「大」指什么、只选中的居中还是都居中），用户：“都居中，然后图标和字再大点。先出设计图”。主控画了甲、乙两档，用户：“甲，写任务书吧”。

原稿在 claude.ai 私有画布「标签居中放大样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色取深色主题的近似值，实现时一律从主题取色；磨砂网页里画不出，只看大小和位置。放大两倍画。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | 现在（P5-165 返工 2b：图标 16、字 14，靠左）；**甲 · 图标 18、字 15，整块居中（采用）**；乙 · 图标 20、字 16（未采用） |
| `Cases.dc.html` | 甲的几种情况：悬停没选中的（× 在最右端，块不挪）、选中的名字很长、名字很短、没选中的名字很长 |

甲的数（界面基础大小下的 pt）：图标 18（框每边宽 1），状态点 6，名字和前缀 15，图标到名字 7；图标和名字当一整块在标签全宽里左右居中，左右各留出 × 那块的位置（样稿 26）；× 的大小和位置不变。
