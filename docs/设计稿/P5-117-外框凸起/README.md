# P5-117 外框凸起样稿

用户 10-15（P5-116 之后）：“我想要的是那种凸出来的感觉。不管是kanban的还是cairn的。理解吗？”

`raised.html` 一个文件里并排三屏，直接用浏览器打开；每屏上面是 Kanban 的 Queued 框，下面是 Cairn 的 Next session 框。配色取 lagoon 主题的近似值，实现时一律从主题取色（不透明的面由面板底色和文字色或强调色混出来）。

| 屏 | 内容 |
| --- | --- |
| 现在 | P5-116 之后的样子：平的，细边加半透明淡底 |
| 轻 | 面不透明、比面板亮一点；顶边内侧亮线、底边内侧暗线（照 P5-51b 左侧栏卡片）；框外一圈小而淡的投影 |
| 重 | 同样做法，面更亮、亮线暗线更明显、投影更深更散 |
