# P5-172 标签状态点样稿

用户 10-23 发来选中标签截图，指着图标右下角的状态点：“我总觉得这个不好看。能否在想的精细一些，出设计稿。”主控出了四种，用户选甲：“我同意甲”，并要干活中时点会呼吸、只改标签。

原稿在 claude.ai 私有画布「标签状态点样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。放大 1.5 倍，每种画四个状态（干活中蓝、空闲绿、等你黄、出错红），干活中的呼吸画成静止的一帧；颜色取深色主题的近似值，图标用橙色方块代替 Claude 的真图标。

| 方案 | 内容 |
| --- | --- |
| 现在 | 6pt 点套 2pt 标签底色的圈，压在图标右下角 |
| 甲 · 点挪到名字后面（用户选定） | 图标完整；名字后面一颗 6pt 的点，对着小写字母中线 |
| 乙 · 图标外一圈状态色细环 | 1.5pt 空隙加 1.5pt 环 |
| 丙 · 精修角标 | 点 5pt、圈 1.5pt，圆心落在图标圆角的弧上 |
| 丁 · 图标下方一道短横 | 10×2.5 的圆头短横 |
