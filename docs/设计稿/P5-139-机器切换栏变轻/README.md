# P5-139 机器切换栏变轻 样稿

用户 10-17（附截图，箭头指着左侧栏顶上的 `This Mac | RTX-5090`）：“我总觉得这块在整个界面有点突兀。”主控列了四个原因（没和下面的框对齐、凹槽加胶囊两层轮廓、粗体比卡片还抢眼、两台平分整宽显得空）和 A 原地变轻、B 小菜单、C 挪到底部三个方向；用户：“先出一张样稿看看”；看过：“A，但是不能丢失现在已经显示的信息哦”。

原稿在 claude.ai 私有画布「Machine switcher redesign」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。配色照截图估的，字号是示意，实现照主题取色、照现有常量。

| 列 | 内容 |
| --- | --- |
| 现在 | 用户截图那样 |
| **A 原地变轻（采用）** | 和下面的框对齐、不要凹槽外框、普通字号不加粗、按字宽靠左排、选中只一层淡底；下面两行画出重连中带计数和 `?2`、连不上的红字和 `!1` |
| B 小菜单（收起、点开） | 没选 |

样稿上没画的：悬停、右键菜单（照旧）、名字很长被截断、放不下折行、浅色主题、磨砂、侧栏收成窄条（窄条不改）。
