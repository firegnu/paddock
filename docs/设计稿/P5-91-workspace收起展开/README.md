# P5-91 workspace 收起和展开的样子 样稿

用户 10-14 看过装好的 P5-89 后：“1: 展开和收缩的图标一样，我觉得应该改一下。2: 展开的情况下，workspace的展开状态（ui层面不明显，不好看出来这是一个展开的workspace）。3: 收缩情况下现在ui太普通了。能不能做一个类似之前agent区域的tab按钮的那个stack的效果。”主控给了收起的两种画法，用户：“甲乙都画出来，我挑”；看过样稿：“收起用7甲乙，展开用8二，写任务文件吧”。

原稿在 claude.ai 私有画布「P5-89 Workspace 样稿」最下面一行「第二轮：收起和展开的样子」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里；画布上六张叫 `FoldNow`、`FoldA`、`FoldB`、`FoldAB`、`OpenBand`、`OpenWell`）。配色照用户截图里的深色主题近似，实现时一律从主题取色；侧栏宽 340 是示意。都是静态的；卡片上的字、`Fine-tuning` 这个 workspace 是占位的，agent 图标是示意画的。

| 文件 | 内容 |
| --- | --- |
| `7-FoldNow.dc.html` | P5-89 装好的样子，对照用：收起和展开同一套底和边、同一个图标 |
| `7a-FoldA.dc.html` | 收起甲：标题前的图标换成里面 agent 的小卡片叠起来（照 P5-76 分屏标签的画法），行本身不变 |
| `7b-FoldB.dc.html` | 收起乙：整行画成一张实底的卡片，下面露出一到两层卡片的边；图标收起时顶上那片填实 |
| `7ab-FoldAB.dc.html` | **采用（收起）**：甲乙一起，行是一摞，图标是 agent 的叠卡 |
| `8-1-OpenBand.dc.html` | 展开一：标题行有自己的一条浅色带子和分隔线，边加深。没采用 |
| `8-2-OpenWell.dc.html` | **采用（展开）**：托盘比侧栏底色深一档，像凹下去的槽，边加深，里面的卡片照旧 |

收起的四张里，展开的那个 workspace 是 P5-89 的样子；展开的两张里，收起的那个也是 P5-89 的样子。做出来是 `7ab-FoldAB` 的收起加 `8-2-OpenWell` 的展开。

样稿上没画的：鼠标停在上面和菜单打开时变亮的样子；只有一个 agent、没有 agent 的 workspace 收起时的样子；浅色主题；左侧栏收成窄条（不变）。
