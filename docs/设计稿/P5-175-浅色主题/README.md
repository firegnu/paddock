# P5-175 浅色主题样稿

用户 10-23 问“还有浅色主题？”（paddock 七套主题全是深色的），说“可以添加一个浅色主题尝试看看。”主控把现有三家主题的官方浅色版各画进一个模拟 paddock 窗口，用户选第一个：“先弄第一个。弄出来我看看。settings里面要有对应的选择哦”。

原稿在 claude.ai 私有画布「浅色主题样稿」，这里是同一份源文件（引用的 `support.js` 不在这里）。颜色照各家发布的值，磨砂下面垫一张浅色壁纸；左侧栏四个 agent 依次是干活中、空闲、等你、出错。

| 方案 | 内容 |
| --- | --- |
| Catppuccin Latte（用户选定） | 和 Catppuccin Mocha 同一家；灰蓝底 `#eff1f5`、侧栏 mantle `#e6e9ef`、字 `#4c4f69`、紫色强调 `#8839ef` |
| Rosé Pine Dawn | 暖米色底 `#faf4ed`、灰紫字，最柔和，对比最低 |
| Tokyo Night Day | 冷灰蓝底 `#e1e2e7`、蓝色正文 `#3760bf`，对比最强 |
