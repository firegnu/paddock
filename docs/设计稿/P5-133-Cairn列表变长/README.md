# P5-133 Cairn 的 Ledger、Lessons 变长以后 样稿

用户 10-17：“另外Ledger和lessons的显示现在是完全平铺，随着item越来越多，会不会显得很长？你要设计一下。”看过样稿后：“选 A，只展开 State，组内新的在上”。

原稿在 claude.ai 私有画布「P5-133 Cairn 账和经验变长样稿」，这里是同一份源文件（`.dc.html`，引用的 `support.js` 不在这里）。配色取 Lagoon 近似值，实现时从主题取色；条目内容取自本仓库的账，日期是示意。画布上还有一张 B（保留两行预览、每组只露最新 5 条加 Show more），用户没选，没有收进来。

| 文件 | 内容 |
| --- | --- |
| `Main.dc.html` | 现在：每条带两行正文预览，全部平铺，49 条约 3,300px |
| `A-Compact.dc.html` | A：标签下一个过滤框（`Filter 49 entries`、`⌘F`）；组头可点，`▾`/`▸` 加条数；每条一行 30px：`#编号`、标题（过长省略）、右边日期；点开的那条显示正文和 Added 等；样稿里 Open、Conventions 收着。注意样稿 State 组内还是从旧到新，用户定的是新的在上 |
| `A-Filter.dc.html` | A 过滤时：框里有字时描边高亮，右边 `6 of 49` 和清除 `×`；组头写 `3 of 15`；命中的字高亮；没有命中的组不显示，收着的组展开；Esc 清掉 |
| `A-Lessons.dc.html` | A 的 Lessons 页：同样一行一条、过滤框，新的在上；只有一组，不可收 |
